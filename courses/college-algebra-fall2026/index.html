SECTION 3.1

Functions and Function Notation

A relation is a set of ordered pairs. It is a function when each input is assigned exactly one output. Learn to read, represent, evaluate, and graph functions.

Learning objectives Determine whether a relation is a function; identify domain and range of ordered pairs; use function notation; find inputs and outputs from formulas, tables, and graphs; apply the vertical line test; recognize toolkit graphs.

Lesson adapted from Section 3.1: Functions and Function Notation (notes prepared by Dr. Setayesh), with interactive explorations and additional guided explanations.

01 · Ordered pairs, domain, and range

Definitions · Relation, domain, range

An ordered pair is written (first component, second component), or (input, output), such as (5, −2) or (m, 3).

A relation is a set of ordered pairs. The domain is the set of first components (inputs or independent-variable values); the range is the set of second components (outputs or dependent-variable values). Use braces { } to write a set, and list each distinct value only once.

Worked example · Finding domain and range

Let R = {(1, 5), (−5, 2), (0, 0), (1, −3)}.

Inputs (first components)

1, −5, 0, 1

Domain = {−5, 0, 1}

The repeated 1 is listed only once.
Outputs (second components)

5, 2, 0, −3

Range = {−3, 0, 2, 5}

Order the distinct values if helpful.

Notice: this relation is not a function, because input 1 has outputs 5 and −3.

Think–Pair–Share 1 · Identify the domain and range

For { (−7, −2), (3, 0), (8, −2), (0, 12), (−15, 9) }, find the number of pairs, domain, and range.

Hint

Take first coordinates for the domain and second coordinates for the range, removing duplicates.

Reveal worked answer

5 pairs. Domain = {−15, −7, 0, 3, 8}. Range = {−2, 0, 9, 12}. Domain values are inputs/independent-variable values; range values are outputs/dependent-variable values.

02 · Is the relation a function?

Definition · Function

A relation is a collection of ordered pairs (input, output). A function assigns exactly one output to each input.

A repeated input with different outputs means it is not a function; repeated outputs are perfectly allowed. A repeated identical pair does not add another element to the relation.

POINT TO REMEMBER

✓ Different inputs may share the same output. For example, (1, 5) and (2, 5) are allowed.

✕ One input cannot lead to different outputs. For example, (1, 5) and (1, 7) are not a function.

Repeating exactly the same ordered pair does not create a conflict: a relation is a set, so duplicate pairs count only once.

Repeated output is okay: { (−2, 3), (0, 3), (2, 5) }. Every input has only one output, even though 3 appears twice.

Repeated input with different outputs is not okay: { (−2, 1), (0, 3), (0, 5), (2, 5) }. Input 0 points to both 3 and 5.

Example · Mapping and the donut shop

Both {(p, m), (q, n), (r, n)} and {(p, x), (q, y), (r, z)} are functions; {(p, x), (q, y), (q, z)} is not, because q maps to two outputs.

03 · Reading function notation

Definition · \(y=f(x)\)

Read “y is a function of x.” The symbol f names the function, x is the input/independent variable, and y = f(x) is the output/dependent variable. f(x) is not “f times x.”

\(y=f(x)\)f: function name · x: input · y: output
\(y=h(m)\)h: function name · m: input · y: output
\(s=v(t)\)v: function name · t: input · s: output
Think–Pair–Share 2 · Explain \(k=g(c)\)

Say the notation aloud; identify the function's name, independent variable, and dependent variable.

Reveal explanation

“k is a function of c.” The function is named g; c is the input/independent variable; k = g(c) is the output/dependent variable.

One input–output rule can be expressed with ordered pairs, a table, a formula, or a graph. An input must have one output, but an output can belong to several inputs.

A graph draws each ordered pair (x, y) as a point. Use the vertical line test in the next activity to decide whether a graph is a function.

Think–Pair–Share 3 · Which examples are functions?

Decide whether (a) inputs 2, 5, 8 mapped to 1, 3, 6; (b) \(y=4-x^2\); and (c) \(x^2+y^2=6\) represent functions of x.

Reveal reasoning

(a) Yes: each input appears once. (b) Yes: each x gives a unique y. (c) No: for x = 0, y can be √6 or −√6; the circle fails the vertical line test.

05 · Vertical line test explorer

Slide a vertical line across the graph. A function has at most one intersection at each x-value.

Definition · Vertical Line Test

A graph represents a function if and only if every vertical line meets the graph at most once. Two intersections at the same x-value prove that it is not a function.

06 · Evaluate an output or solve for an input

Example 4 · Given an input

For \(f(x)=x^3-6x+1\), find \(f(3)\).

\(f(3)=3^3-6(3)+1=27-18+1=\boxed{10}.\)

Therefore, (3, 10) belongs to the graph.

Example 5 · Given an output

For \(g(p)=\sqrt{3+2p}\), solve \(g(p)=3\).

\(\sqrt{3+2p}=3 \implies 3+2p=9 \implies \boxed{p=3}.\)

Check: \(\sqrt{3+2(3)}=3\).

Key distinction: When finding \(f(a)\), replace the input with a. When solving \(f(x)=b\), set the output equal to b and solve for possible inputs (there may be more than one).

Think–Pair–Share 4 · Evaluate \(f(-2)\) and \(f(a)\)

Use \(f(x)=x^3-6x+1\).

Hint

Replace every x with −2, or with the symbol a. Remember \((-2)^3=-8\).

Show the answer

\(f(-2)=(-2)^3-6(-2)+1=-8+12+1=\boxed{5}\). Thus (−2, 5) is on the graph. \(f(a)=a^3-6a+1\).

Think–Pair–Share 5 · Solve \(h(m)=4\)

Given \(h(m)=m^2-5\), find all inputs m producing output 4.

Show the answer

\(m^2-5=4 \implies m^2=9 \implies \boxed{m=-3\text{ or }m=3}\). A function can have two inputs for the same output.

09 · Read input and output values from a graph

To find f(a), start at x = a and read the corresponding height. To solve f(x) = b, draw the horizontal line y = b and find every intersection's x-coordinate.

Explore the example graph \(f(x)=(x-1)^2\). In particular, it shows \(f(-1)=4\) and \(f(x)=1\) at two inputs, x = 0 and x = 2, as in the graph-reading example of the notes.

Show the answers

SECTION 3.2

Domain and Range

The domain contains allowable inputs (x-values); the range contains actual outputs (y-values). An open endpoint is excluded; a filled endpoint is included.

Learning goals Use interval notation, recognize excluded denominators and square-root restrictions, and determine domain and range from graphs.

01 · Interval notation — examples & interactive builder

Choose endpoints and whether to include them. The number line and mathematical notation update together.

INTERVAL NOTATION · Reference guide

Parentheses ( ) exclude endpoints; brackets [ ] include endpoints. Infinity is never an endpoint you can include, so always use parentheses with ±∞.

Open interval(a, b)a < x < b
Closed interval[a, b]a ≤ x ≤ b
Left included[a, b)a ≤ x < b
Right included(a, b]a < x ≤ b
Unbounded left(−∞, a)x < a
Unbounded left, includes a(−∞, a]x ≤ a
Unbounded right(a, ∞)x > a
Unbounded right, includes a[a, ∞)x ≥ a
All real numbers(−∞, ∞)x ∈ ℝ
Union of intervals(−∞, −2) ∪ [1, 4)x < −2 or 1 ≤ x < 4
Visual key: ○ open circle = excluded; ● filled circle = included; ←/→ = extends indefinitely. Try the preset buttons to see each type on a number line.

02 · Domain restriction laboratory

Experiment with the denominator or radicand. Watch what inputs become forbidden.

General domain rules (over the real numbers)

1 · DenominatorsEvery denominator must be nonzero: for 1/g(x), require g(x) ≠ 0. Example: 1/(x − 3) requires x ≠ 3.
2 · Even-index rootsFor √[2n]{g(x)} require g(x) ≥ 0. Example: √(x − 4) requires x ≥ 4.
3 · Even roots in a denominatorFor 1/√[2n]{g(x)} require g(x) > 0. Example: 1/√(x − 4) requires x > 4.
4 · Odd-index roots√[2n+1]{g(x)} permits negative, zero, and positive radicands (subject to g itself being defined). Example: ∛(x + 1) is defined for all real x.
5 · Odd roots in a denominatorFor 1/√[2n+1]{g(x)}, require g(x) ≠ 0. Example: 1/∛(x − 4) excludes x = 4.

Combined expressions: apply every restriction simultaneously; the domain is the intersection of all allowed inputs.
