SECTION 3.1

Functions and Function Notation

A relation is a set of ordered pairs. It is a function when each input is assigned exactly one output. Learn to read, represent, evaluate, and graph functions.

Learning objectives Determine whether a relation is a function; identify domain and range of ordered pairs; use function notation; find inputs and outputs from formulas, tables, and graphs; apply the vertical line test; recognize toolkit graphs.

Learning objectives informed by the Section 3.1 course notes (Dr. Setayesh). The scenarios, visualizations, and practice activities here are newly authored.

01 · Ordered pairs, domain, and range

Start with a point

An ordered pair (x, y) connects an input to an output. A relation is a set of such pairs. Its domain contains the distinct x-values, and its range contains the distinct y-values. Repeated values appear only once in a set.

02 · Is the relation a function?

Definition · Function

A relation is a collection of ordered pairs (input, output). A function assigns exactly one output to each input.

A repeated input with different outputs means it is not a function; repeated outputs are perfectly allowed. A repeated identical pair does not add another element to the relation.

POINT TO REMEMBER

✓ Outputs may repeat. For example, (−3, 2) and (4, 2) have different inputs and one shared output.

✕ One input cannot have two different outputs. For example, (−3, 2) and (−3, −1) break the rule.

Repeating exactly the same ordered pair does not create a conflict: a relation is a set, so duplicate pairs count only once.

03 · Reading function notation

What does f(x) mean?

In y = f(x), the letter f is the function’s name, x is the independent input, and y is the dependent output. The parentheses indicate an input to a function—not multiplication.

05 · Vertical line test explorer

Slide a vertical line across the graph. A function has at most one intersection at each x-value.

Definition · Vertical Line Test

A graph represents a function if and only if every vertical line meets the graph at most once. Two intersections at the same x-value prove that it is not a function.

06 · Forward and backward: from inputs to outputs

Evaluating q(a) means substituting an input a. Solving q(x) = b means finding every input producing output b. The two tasks are not the same.

      Extra example: what if dividing is necessary?

      In our main function the squared expression has a coefficient of 1, so there is nothing to divide by. Compare this variation:

      1. Start with the equation2(x − 2)² + 1 = 9
      2. Subtract 1 from both sides2(x − 2)² = 9 − 1 = 8
      3. Divide both sides by 2(x − 2)² = 8 ÷ 2 = 4
      4. Take both square rootsx − 2 = ±√4 = ±2
      5. Add 2 to both sidesx = 2 − 2 = 0 or x = 2 + 2 = 4

      The extra coefficient is why this version requires division before taking square roots.

      Explain: How can two different inputs give the same output without breaking the definition of a function?

      SECTION 3.2

      Domain and Range

      Every function has a collection of allowed inputs (its domain) and possible outputs (its range). Learn to read these sets on a number line, calculate restrictions from formulas, and project a graph onto its axes.

      Learning objectives Translate inequalities into interval and set-builder notation; determine the domain of a function from its equation; and read both domain and range from a graph.

      Concepts and lesson sequence adapted from the supplied Section 3.2 notes; examples, graphics, and activities are newly designed for this page.

      01 · Interval notation and number lines

      How to write an interval

      Write the smaller value first, then the larger value. Use a parenthesis ( ) when a boundary is excluded, and a bracket [ ] when it is included. Always write parentheses beside −∞ and ∞: infinity is not a real number you can reach.

      Set-builder notation: {x ∈ ℝ | condition} means “all real numbers x such that the stated condition holds.” The symbol ∪ joins two pieces of a set.

      INTERVAL NOTATION · Quick reference

      Both excluded(a, b)a < x < b
      Both included[a, b]a ≤ x ≤ b
      Only a included[a, b)a ≤ x < b
      Only b included(a, b]a < x ≤ b
      Left ray(−∞, b]x ≤ b
      Right ray(a, ∞)x > a
      All real numbers(−∞, ∞)x ∈ ℝ
      Separate pieces(−∞, −1) ∪ [2, 5)x < −1 or 2 ≤ x < 5

      02 · Domain from a function's equation

      What is a “good” input?

      An input x belongs to the domain precisely when the rule gives a real, defined output. For a polynomial, every real input works. For a rational expression, no denominator may equal zero. For an even root, its radicand must be nonnegative; if that root appears in a denominator, it must be strictly positive.

      DenominatorRequire D(x) ≠ 0Never divide by zero.
      Square rootRequire R(x) ≥ 0Zero is allowed under √.
      √ in denominatorRequire R(x) > 0Zero is not allowed there.
      Polynomial / cube rootEvery real x worksUnless another restriction applies.
