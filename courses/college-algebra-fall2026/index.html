SECTION 3.1

Functions and Function Notation

A function assigns exactly one output to every input. Multiple inputs may share the same output; one input cannot have two different outputs.

Learning goals Identify functions from relations, tables, and graphs; evaluate function notation; read outputs and inputs; recognize parent graphs.

01 · Build a relation

Definition · Function

A relation is a set of ordered pairs (input, output). It is a function exactly when each input is assigned one and only one distinct output.

✓ Two different inputs may have the same output. ✕ The same input cannot lead to two different outputs.

Step 1. Change the outputs below. Toggle the extra ordered pair to repeat an input. Watch the ordered-pair cards and the mapping diagram change.

See the rule with two examples

Repeated output is okay: { (−2, 3), (0, 3), (2, 5) }. Every input has only one output, even though 3 appears twice.

Repeated input with different outputs is not okay: { (−2, 1), (0, 3), (0, 5), (2, 5) }. Input 0 points to both 3 and 5.

SECTION 3.2

Domain and Range

The domain contains allowable inputs (x-values); the range contains actual outputs (y-values). An open endpoint is excluded; a filled endpoint is included.

Learning goals Use interval notation, recognize excluded denominators and square-root restrictions, and determine domain and range from graphs.

05 · Interactive interval builder

Choose endpoints and whether to include them. The number line and mathematical notation update together.

06 · Domain restriction laboratory

Experiment with the denominator or radicand. Watch what inputs become forbidden.

07 · Graph and range explorer

Move the vertex of \(f(x)=a(x-h)^2+k\), then observe the domain and range. Change the sign of a to flip the parabola.
