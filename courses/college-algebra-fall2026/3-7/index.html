Where we are coming from

In 3.5 Part II · Transformations: Reflections, Stretches, and Compressions, we reflected, stretched, and compressed graphs and combined transformations.

An inverse function runs a function backward: it takes an output and returns the input that produced it. That only works when no two inputs share an output, so we first learn to recognize one-to-one functions.

Learning objectives Verify inverse functions; determine the domain and range of an inverse function and restrict the domain of a function to make it one-to-one; find or evaluate the inverse of a function; use the graph of a one-to-one function to graph its inverse on the same axes.

01 · Swap the inputs and outputs

Idea · Reversing a function

Reversing a function swaps every ordered pair (x, y) to (y, x). The result is a function only if no output of the original was repeated. Such a function is called one-to-one, and its reversal is the inverse function f⁻¹.

Careful: f⁻¹(x) is not 1/f(x). The −1 is a label, not an exponent.

INTERACTIVE · SWAP AND CHECK

02 · The horizontal line test

Definition · One-to-one and the horizontal line test

A function is one-to-one when every output comes from exactly one input. On a graph: no horizontal line meets the graph more than once.

INTERACTIVE · SLIDE A HORIZONTAL LINE

03 · The graph of an inverse: reflect over y = x

Facts · Graphs, domains, and ranges

If (a, b) is on the graph of f, then (b, a) is on the graph of f⁻¹. So the two graphs are reflections of each other over the line y = x, and the domain and range switch: domain of f⁻¹ = range of f, and range of f⁻¹ = domain of f.

INTERACTIVE · MIRROR POINT

Slide the point along the graph of f. Its mirror image (b, a) traces the graph of f⁻¹.

04 · Verify inverses by composition

Test · Inverses undo each other

f and g are inverses exactly when f(g(x)) = x and g(f(x)) = x for every x in the appropriate domains.

INTERACTIVE · DO THEY UNDO EACH OTHER?

05 · Find the inverse from a formula

How to find f⁻¹

1. Check that f is one-to-one, and replace f(x) with y.  2. Interchange x and y.  3. Solve for y.  4. Replace y with f⁻¹(x).

INTERACTIVE · STEP BY STEP

Choose a function and reveal the algebra one step at a time. Then test the answer: f⁻¹ should send f(x) back to x.

06 · Restrict the domain to make a function one-to-one

The parabola h(x) = (x − 2)² − 1 fails the horizontal line test. Keep only one half of it, either x ≥ 2 or x ≤ 2, and the restricted function has an inverse.

INTERACTIVE · KEEP HALF THE PARABOLA

WRAP-UP

Check your understanding · Inverse Functions

Answer each question on paper first, then open the answer to check yourself.

  1. What property must a function have in order to have an inverse function, and how can you check it on a graph?

    Show answer

    It must be one-to-one: no output is repeated. On a graph, no horizontal line meets the graph more than once.

  2. How are the domain and range of f and f⁻¹ related?

    Show answer

    They switch: the domain of f⁻¹ is the range of f, and the range of f⁻¹ is the domain of f.

  3. Find the inverse of f(x) = (x + 7)/3.

    Show answer

    y = (x + 7)/3. Swap: x = (y + 7)/3. Solve: 3x = y + 7, so y = 3x − 7. Therefore f⁻¹(x) = 3x − 7.

  4. How can you verify that two functions f and g are inverses?

    Show answer

    Compose them in both orders. If f(g(x)) = x and g(f(x)) = x, they are inverses.
