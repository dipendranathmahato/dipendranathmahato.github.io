Where we are coming from

In 3.4 · Composition of Functions, we combined functions and fed the output of one function into another.

Every toolkit graph from Section 3.1 can be moved. Adding a number outside the function moves the graph up or down; changing the input inside the function moves it left or right. The shape never changes, only its position.

Learning objectives Graph functions using vertical and horizontal shifts; build tables for shifted functions; combine vertical and horizontal shifts; write a formula for a shifted toolkit graph.

01 · Vertical shifts: g(x) = f(x) + k

Rule · Vertical shift

The graph of g(x) = f(x) + k is the graph of f moved up k units if k > 0 and down |k| units if k < 0. Every output changes by k; the inputs stay the same.

INTERACTIVE · SLIDE UP AND DOWN

Pick a toolkit function and move k. The gray dashed graph is f; the orange graph is g. Arrows show where the key points go.

02 · Horizontal shifts: g(x) = f(x − h)

Rule · Horizontal shift

The graph of g(x) = f(x − h) is the graph of f moved right h units if h > 0 and left |h| units if h < 0. Every input changes; the outputs stay the same.

Watch the sign: f(x + 4) = f(x − (−4)) moves the graph left 4, and f(x − 2) moves it right 2.

Predict first

To graph g(x) = (x + 4)², which way do we move the graph of y = x²?

INTERACTIVE · SLIDE LEFT AND RIGHT
COMMON MISTAKES
  • A “+” inside moves the graph left, and a “−” inside moves it right. Find where the inside equals 0 to check.
  • Inside changes inputs, outside changes outputs. f(x) + 3 is a vertical shift; f(x + 3) is a horizontal shift.

03 · Shifting a function given by a table

A vertical shift adds k to every output. A horizontal shift changes every input: for s(t + c) we subtract c from each input, and for s(t − c) we add c. Choose a shift to build the new table.

04 · Combining vertical and horizontal shifts

Rule · g(x) = f(x − h) + k

Shift f horizontally by h (right if h > 0, left if h < 0) and vertically by k (up if k > 0, down if k < 0). Each point (x, y) of f moves to (x + h, y + k).

INTERACTIVE · MOVE A CUBIC

Here f(x) = (x + 3)(x + 1)(x − 1) has x-intercepts −3, −1, and 1 and y-intercept −3. Move it with h and k, or load one of the two examples.

WRAP-UP

Check your understanding · Shifts

Answer each question on paper first, then open the answer to check yourself.

  1. How does the graph of g(x) = f(x) + k compare with the graph of f?

    Show answer

    It is the same graph moved up k units when k > 0 and down |k| units when k < 0. Only the outputs change.

  2. How does the graph of g(x) = f(x − h) compare with the graph of f?

    Show answer

    It moves right h units when h > 0 and left |h| units when h < 0. Only the inputs change. For example, f(x + 5) moves the graph left 5.

  3. Describe g(x) = f(x − 3) + 2, and find where the point (1, 0) of f goes.

    Show answer

    Right 3 and up 2. The point (1, 0) moves to (1 + 3, 0 + 2) = (4, 2).

  4. Write a formula for the graph of y = √x shifted 1 unit right and 2 units up.

    Show answer

    h(x) = √(x − 1) + 2.
