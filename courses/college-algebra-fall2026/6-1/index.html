Where we are coming from

In 5.6 · Rational Functions, rational functions have holes and vertical, horizontal, or slant asymptotes.

Polynomials raise x to a fixed power. Exponential functions flip that around: a fixed base is raised to the power x. The result is growth (or decay) by the same factor at every step, which is exactly how savings accounts, populations, and medicines behave.

Learning objectives Evaluate exponential functions; use compound interest formulas; evaluate exponential functions with base e.

01 · What makes a function exponential?

Definition · Exponential function

f(x) = a·bˣ, where the initial value a ≠ 0 and the base b > 0, b ≠ 1. The domain is (−∞, ∞); the range is (0, ∞) if a > 0 and (−∞, 0) if a < 0; the y-intercept is (0, a); the horizontal asymptote is y = 0.

INTERACTIVE · THE FOUR SHAPES OF a·bˣ

Change a and b. Watch the table: each step to the right multiplies the output by b. The four sign/size combinations give the four graphs A–D.

02 · Exponential or not?

Compare each function with y = a·bˣ: the variable must be in the exponent, and the base must be a positive constant other than 1.

03 · Shifting exponential graphs

The transformations from Section 3.5 apply: in y = a·bx − h + k, the graph of a·bˣ moves h units horizontally and k units vertically. A vertical shift moves the horizontal asymptote to y = k; a horizontal shift does not move it.

04 · The number e

The natural base e

As n grows without bound, (1 + 1/n)ⁿ approaches an irrational number, e ≈ 2.718282. It was introduced by Jacob Bernoulli in 1683 and later named by Leonhard Euler. Use the eˣ key on a calculator: e³ ≈ 20.0855 and e⁻² ≈ 0.1353.

05 · Compound interest

Formulas

Compounded n times a year: A(t) = P(1 + r/n)nt, and for an unknown present value P = A(1 + r/n)−nt. Here P is the principal, r the annual rate as a decimal, n the number of compounding periods per year (annually 1, semi-annually 2, quarterly 4, monthly 12, weekly 52, daily 365), and t the time in years.

Compounded continuously: A(t) = Pert, and P = Ae−rt.

WRAP-UP

Check your understanding · Exponential Functions

Answer each question on paper first, then open the answer to check yourself.

  1. Which of these are exponential functions: f(x) = 5ˣ, g(x) = 7x, h(x) = −4ˣ + 5, q(x) = −2x³?

    Show answer

    f(x) = 5ˣ (a = 1, b = 5) and h(x) = −4ˣ + 5 (the graph of −4ˣ shifted up 5). g is linear and q is a polynomial.

  2. For g(x) = 5(2/5)x − 1 − 3, find the y-intercept, the horizontal asymptote, and the range.

    Show answer

    g(0) = 5(2/5)⁻¹ − 3 = 5(5/2) − 3 = 9.5, so (0, 9.5). The horizontal asymptote is y = −3, and since a = 5 > 0 the range is (−3, ∞).

  3. An account opens with $830 at 10.6% compounded weekly. What is it worth in 20 years?

    Show answer

    A = 830(1 + 0.106/52)52·20 ≈ $6,899.94.

  4. How much must you invest now at 14.7% compounded continuously to have $25,000 in 8 years?

    Show answer

    P = 25,000e−0.147·8 = 25,000e−1.176 ≈ $7,712.76.
