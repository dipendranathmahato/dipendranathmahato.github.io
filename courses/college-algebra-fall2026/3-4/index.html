Where we are coming from

In 3.3 · Rates of Change and Behavior of Graphs, we measured how fast a function changes and where its graph rises, falls, or stays flat.

Functions can be combined like numbers: added, subtracted, multiplied, and divided. They can also be chained: the output of one function becomes the input of the next. That chain is called a composition.

Learning objectives Combine functions using algebraic operations; create a new function by composition; evaluate composite functions from formulas, tables, and graphs; find the domain of a composite function.

01 · Combining functions with algebraic operations

Definition · Function arithmetic

For functions f and g, combine the outputs: (f + g)(x) = f(x) + g(x), (f − g)(x) = f(x) − g(x), (fg)(x) = f(x)·g(x), and (f/g)(x) = f(x)/g(x), where g(x) ≠ 0.

INTERACTIVE · OPERATION LAB

Pick a pair of functions and an operation. The steps simplify the new function, the graph shows f, g, and the result, and the check row confirms the result at one input.

COMMON MISTAKES
  • Distribute the minus sign in f − g: (x + 3) − (x² − 9) = x + 3 − x² + 9.
  • Find the domain of a quotient before simplifying. Canceling a factor does not bring back an input that made the denominator zero.

02 · The composition machine

Definition · Composite function

(f ∘ g)(x) = f(g(x)), read “f of g of x.” The input x goes into g first; the output g(x) then becomes the input of f.

Composition is not multiplication, and in general f(g(x)) ≠ g(f(x)).

INTERACTIVE · FOLLOW THE INPUT

Choose two functions, the order, and an input. Watch the number travel through the inner function and then the outer function. Below, the formula for the composite function is built by substitution.

Try this: Keep the same input and switch the order between f ∘ g and g ∘ f. Explain to a partner why the two orders usually give different outputs, using the chain of boxes.

03 · Composition from a table

To evaluate f(g(1)) from a table, first look up the inner value g(1), then use that number as the input of the outer function.

04 · Composition from graphs

With graphs, read the inner function first: go up from x to the inner graph and read its output. Then find that number on the x-axis of the outer graph and read the final output.

05 · The domain of a composite function

How to find the domain of f(g(x))

1. Find the domain of g.  2. Find the domain of f.  3. From the domain of g, remove every x for which g(x) is not in the domain of f.

INTERACTIVE · TWO GATES

An input must pass two gates: g must accept x, and f must accept g(x). Choose a pair of functions and test inputs.

WRAP-UP

Check your understanding · Composition of Functions

Answer each question on paper first, then open the answer to check yourself.

  1. How would you define a composite function (f ∘ g)(x)?

    Show answer

    It is f(g(x)): the input x goes into g, and the output g(x) is used as the input of f.

  2. How is f(g(x)) different from g(f(x))? Use f(x) = 2x − 1 and g(x) = x².

    Show answer

    f(g(x)) = 2x² − 1, but g(f(x)) = (2x − 1)² = 4x² − 4x + 1. The order matters.

  3. Find (f − g)(x) for f(x) = x² + 1 and g(x) = 3x − 2.

    Show answer

    (x² + 1) − (3x − 2) = x² + 1 − 3x + 2 = x² − 3x + 3.

  4. How do you find the domain of f(g(x))?

    Show answer

    Start with the domain of g, then remove every x for which g(x) is not in the domain of f. For f(x) = √x and g(x) = x − 5, we need x − 5 ≥ 0, so the domain is [5, ∞).
