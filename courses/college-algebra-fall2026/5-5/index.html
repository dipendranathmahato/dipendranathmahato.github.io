Where we are coming from

In 5.3 · Graphs of Polynomial Functions, zeros and their multiplicities describe how a polynomial graph meets the x-axis.

A degree-n polynomial has at most n zeros. For a quadratic we have the quadratic formula; for higher degrees we need a strategy. This section builds one: divide, read the remainder, and use a zero you know to factor the rest.

Learning objectives Evaluate a polynomial using the Remainder Theorem; use the Factor Theorem to solve a polynomial equation; use the Rational Zero Theorem to find rational zeros.

01 · Dividing polynomials

The Division Algorithm

Whole numbers: 11 ÷ 4 gives quotient 2 and remainder 3, so 11 = 4 × 2 + 3. Polynomials work the same way: for a dividend f(x) and a nonzero divisor d(x) of lower or equal degree, there are unique polynomials q(x) and r(x) with

f(x) = d(x) · q(x) + r(x),

where the remainder r(x) is 0 or has smaller degree than d(x).

INTERACTIVE · LONG DIVISION, ONE MOVE AT A TIME

Each round repeats four moves: divide the leading terms, multiply, subtract, and bring down the next term.

02 · The Remainder Theorem

Theorem · Remainder Theorem

If a polynomial f(x) is divided by x − k, the remainder is f(k). So to find the remainder: set x − k = 0 to get x = k, then evaluate f(k). No long division is needed.

INTERACTIVE · REMAINDER = HEIGHT OF THE GRAPH AT k

The remainder is the y-value of the graph at x = k. Pick an example or type your own coefficients.

03 · The Factor Theorem

Theorem · Factor Theorem

From f(x) = (x − k)q(x) + f(k): if f(k) = 0, then f(x) = (x − k)q(x), so x − k is a factor. Conversely, if x − k is a factor, then x = k is a zero. In short: x − k is a factor of f(x) exactly when f(k) = 0.

INTERACTIVE · FACTOR OR NOT?

Decide whether each binomial is a factor. Evaluate f(k) first; the remainder decides.

04 · Synthetic division

How to divide by x − k with synthetic division

1. Write k for the divisor. 2. Write the coefficients of the dividend, using 0 for any missing power. 3. Bring the leading coefficient down. 4. Multiply it by k and write the product in the next column. 5. Add the column. 6. Repeat steps 4 and 5 to the last column. 7. The last number is the remainder; the others are the coefficients of the quotient, one degree lower than the dividend.

INTERACTIVE · WATCH THE NUMBERS MOVE

05 · Factoring a cubic and finding all its zeros

Strategy

1. Divide by a known factor x − k with synthetic division. 2. Confirm the remainder is 0. 3. Write f(x) = (x − k) · (quadratic quotient). 4. Factor the quadratic if possible. 5. Read off all the zeros.

No factor given? The Rational Zero Theorem lists the candidates: if p/q (in lowest terms) is a rational zero of a polynomial with integer coefficients, then p divides the constant term and q divides the leading coefficient.

INTERACTIVE · HUNT FOR A ZERO, THEN FACTOR

Click a candidate to test it with synthetic division. A remainder of 0 unlocks the factorization.

WRAP-UP

Check your understanding · Zeros of Polynomial Functions

Answer each question on paper first, then open the answer to check yourself.

  1. Use the Remainder Theorem to find the remainder when g(x) = x⁴ + 7x³ − 10x² + 5x − 8 is divided by x + 4.

    Show answer

    x + 4 = 0 gives x = −4. g(−4) = 256 − 448 − 160 − 20 − 8 = −380, so the remainder is −380.

  2. Is x + 2 a factor of h(x) = −x⁴ + 4x³ + 12x²? What does that say about x = −2?

    Show answer

    h(−2) = −16 − 32 + 48 = 0, so x + 2 is a factor and x = −2 is a zero of h.

  3. Use synthetic division to divide f(x) = x³ − 5x + 7 by x + 3.

    Show answer

    Coefficients 1, 0, −5, 7 with k = −3 give the bottom row 1, −3, 4 | −5. So f(x) = (x + 3)(x² − 3x + 4) − 5.

  4. Factor f(x) = x³ + 4x² − 4x − 16 given that x − 2 is a factor, and find all its zeros.

    Show answer

    Synthetic division by 2 gives 1, 6, 8 | 0, so f(x) = (x − 2)(x² + 6x + 8) = (x − 2)(x + 2)(x + 4). The zeros are 2, −2, and −4.
