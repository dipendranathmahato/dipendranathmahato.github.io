One linear equation in x and y has infinitely many solutions: every point on its line. A system asks for the points that satisfy both equations at once, which is where the two lines meet.

Learning objectives Solve systems of equations by graphing, by substitution, and by addition (elimination); identify independent, inconsistent, and dependent systems.

01 · Is an ordered pair a solution?

Definition · Solution of a system

An ordered pair (x, y) is a solution of a system when it makes every equation true. To check, substitute the pair into each equation. On a graph, a solution is a point of intersection of the lines.

INTERACTIVE · TEST A POINT

Move the point and watch each equation turn true or false. The point is a solution only when both checks are true.

02 · Solving by graphing, and the three types of systems

Three possibilities

Independent: the lines cross at one point, so there is exactly one solution. Inconsistent: the lines are parallel, so there is no solution. Dependent: the two equations describe the same line, so there are infinitely many solutions.

INTERACTIVE · TWO LINES

Write each equation as y = mx + b, then change the slopes and intercepts. Slopes decide the type: different slopes cross once; equal slopes are parallel or identical.

03 · Solving by substitution

Method · Substitution

1. Solve one equation for one variable.  2. Substitute that expression into the other equation and solve the one-variable equation.  3. Substitute back to find the other variable, and check the pair in both equations.

INTERACTIVE · SUBSTITUTION, ONE STEP AT A TIME

Pick an example or type your own coefficients for ax + by = c. Step through the method; the graph confirms the answer at the end.

04 · Solving by addition (elimination)

Method · Addition

1. Line up x, y, and the constants.  2. If one variable has opposite coefficients, add the equations to eliminate it.  3. If not, multiply one or both equations by numbers that create opposite coefficients, then add.  4. Solve, substitute back, and check.

INTERACTIVE · CHOOSE THE MULTIPLIERS

Choose which variable to eliminate and the two multipliers. When the chosen variable has opposite coefficients, the sum eliminates it. Stuck? Press Suggest multipliers.

COMMON MISTAKES
  • Multiply the whole equation, including the constant on the right side.
  • Both variables canceled? A false statement such as 0 = 7 means no solution (inconsistent); a true statement such as 0 = 0 means infinitely many solutions (dependent).

05 · Classify the system

Decide the type of each system. Use slopes, or what happens when you try to eliminate a variable.
