Shifts move a graph without changing its shape. This part changes the shape: a negative sign flips the graph over an axis, and a multiplier stretches or squeezes it. A multiplier outside the function acts on outputs (vertical); a multiplier inside acts on inputs (horizontal).

Learning objectives Graph functions using reflections about the x-axis and the y-axis; graph functions using vertical and horizontal stretches and compressions; combine several transformations in the correct order.

01 · Reflections over the x-axis and the y-axis

Rule · Reflections

g(x) = −f(x) reflects the graph over the x-axis: every output is multiplied by −1.

g(x) = f(−x) reflects the graph over the y-axis: every input is multiplied by −1.

02 · Vertical stretches and compressions: g(x) = a·f(x)

Rule · Vertical stretch or compression

Multiply every output by a. If |a| > 1 the graph is stretched vertically; if 0 < |a| < 1 it is compressed vertically. If a < 0, there is also a reflection over the x-axis.

03 · Horizontal stretches and compressions: g(x) = f(bx)

Rule · Horizontal stretch or compression

Every input is multiplied by 1/b. If |b| > 1 the graph is compressed horizontally by a factor of 1/|b|; if 0 < |b| < 1 it is stretched horizontally by a factor of 1/|b|. If b < 0, there is also a reflection over the y-axis.

COMMON MISTAKES
  • Inside multipliers work “backwards”: f(2x) is narrower (compressed by 1/2), not wider.
  • Outside affects outputs, inside affects inputs. 2f(x) doubles heights; f(2x) halves x-coordinates.

05 · Combining transformations step by step

Order for k(x) = a·f(bx + c) + d

First factor the inside: bx + c = b(x − h) with h = −c/b. Then transform the inputs (horizontal stretch or compression and reflection, then the horizontal shift h), and finally the outputs (vertical stretch or compression and reflection by a, then the vertical shift d).
