Where we are coming from

In 6.3 · Logarithmic Functions, a logarithm is an exponent: y = log_b x means bʸ = x.

Since y = logb x is the inverse of y = bˣ, its graph is the exponential graph reflected over the line y = x. Inputs and outputs trade places: the domain of the logarithm is the range of the exponential, and the horizontal asymptote becomes a vertical one.

Learning objectives Identify the domain of a logarithmic function; graph logarithmic functions.

01 · The logarithm as a reflection

Characteristics of y = logb x

Domain (0, ∞) and range (−∞, ∞), the reverse of y = bˣ. Vertical asymptote x = 0. Key points (1/b, −1), (1, 0) (the x-intercept), and (b, 1). No y-intercept. Increasing if b > 1, decreasing if 0 < b < 1.

INTERACTIVE · REFLECT bˣ OVER y = x

Slide the reflection from 0% to 100% to watch each point (x, y) travel to (y, x).

02 · The domain of a logarithmic function

Rule · The argument must be positive

In y = logb(argument), set the argument > 0 and solve the inequality. The base, a vertical stretch, and a vertical shift do not affect the domain. Remember to flip the inequality when dividing by a negative number.

INTERACTIVE · SOLVE ARGUMENT > 0

03 · Graphing with transformations

To graph y = a·logb(x − h) + k: start from the key points of logb x, multiply each y-coordinate by a, add h to each x-coordinate (the vertical asymptote moves to x = h), then add k to each y-coordinate.

04 · Summary: fill in the blanks

Complete the summary of transformations of y = a·logb(x − c) + d, then check.

  1. Vertical where |a| > 1, such as y = 5log₈(x).
  2. Vertical where 0 < |a| < 1, such as y = (1/5)log₈(x).
  3. Reflection over the if a < 0, such as y = −5log₈(x).
  4. shift, c units to the if c > 0, such as y = log₈(x − 2).
  5. shift, |c| units to the if c < 0, such as y = log₈(x + 2) = log₈(x − (−2)).
  6. shift, d units if d > 0, such as y = log₈(x) + 1.
  7. shift, |d| units if d < 0, such as y = log₈(x) − 1.

WRAP-UP

Check your understanding · Graphs of Logarithmic Functions

Answer each question on paper first, then open the answer to check yourself.

  1. Find the domains of f(x) = (1/2)log(7 − x) − 3 and g(x) = ln(2x + 6) + 4.

    Show answer

    7 − x > 0 gives x < 7: (−∞, 7). 2x + 6 > 0 gives x > −3: (−3, ∞).

  2. What are the key points and the vertical asymptote of y = log₂(x + 1) + 4?

    Show answer

    (1/2, −1) → (−1/2, 3), (1, 0) → (0, 4), (2, 1) → (1, 5). Vertical asymptote x = −1; domain (−1, ∞).

  3. Graph y = −3log₄(x + 5) − 2 from y = log₄x and give its domain.

    Show answer

    (1/4, −1) → (−19/4, 1), (1, 0) → (−4, −2), (4, 1) → (−1, −5). Vertical asymptote x = −5; domain (−5, ∞).
