CHAPTER 1.1 ALGEBRA REVIEW

Review of Functions

Functions convert inputs into well-defined outputs. Before studying limits and derivatives, you should be able to interpret them algebraically, visually, and numerically.

By the end of this chapter, you should be able to
  • Use function notation and evaluate functions.
  • Distinguish domain, codomain and range, and use interval notation.
  • Identify valid functions from mappings, tables and graphs.
  • Find domains, zeros and intercepts, including for radical functions.
  • Work with piecewise-defined functions and the vertical line test.

1. What makes a relation a function?

DEFINITION

A function $f:A\to B$ assigns exactly one element $f(x)\in B$ to each input $x\in A$. We call $A$ the domain and $B$ a codomain. The range is the set of outputs that actually occur:

$\operatorname{Range}(f)=\{f(x):x\in A\}\subseteq B$

Explore a mapping

Change a mapping arrow to see the difference between a relation and a function.

DomainCodomain

Why can two inputs share an output?

Uniqueness is a requirement for each input, not each output. Both $f(1)=4$ and $f(-1)=4$ are allowed. But a single input cannot map to both $4$ and $9$.

2. Domain, range and interval notation

Before drawing a function, determine which inputs are allowed and which outputs the function actually produces. The domain and range answer two different questions.

REMEMBER · DOMAIN

The domain is the set of every permitted input $x$ for which $f(x)$ is defined.

$D_f=\{x: f(x)\text{ is defined}\}$

REMEMBER · RANGE

The range is the set of output values $f(x)$ that actually occur as $x$ runs through the domain.

$R_f=\{f(x):x\in D_f\}$

Two rules to check first
  • Denominator: it can never be zero. For $\frac{1}{x-1}$, exclude $x=1$.
  • Square root (over the real numbers): the expression under $\sqrt{\phantom{x}}$ must be greater than or equal to zero. For $\sqrt{4-3x}$, require $4-3x\ge0$, giving $x\le \frac43$.

These conditions concern real-valued functions. A polynomial such as $x^2-4$ has domain $\mathbb R$.

Guided examples: domain and range

We will study the two functions separately. Open the reasoning under each one and compare their conclusions afterward.

Example A $f(x)=x^2-4$

This is a polynomial: all real values of $x$ are allowed. Its graph is an upward-opening parabola.

Step 1 · Determine the domain

Substituting any real $x$ into $x^2-4$ always produces a real number. There are no denominators or square roots restricting the inputs.

Domain: $D_f=(-\infty,\infty)$.

Step 2 · Determine the range

Because $x^2\ge0$, we know $x^2-4\ge-4$. Equality occurs at $x=0$, so the minimum value $-4$ is included. The outputs increase without bound.

Range: $R_f=[-4,\infty)$.

Key point: every real input is allowed, but outputs below $-4$ never occur.

Example B $g(x)=\sqrt{x^2-4}$

This is a square-root function. We must check the expression inside the radical before choosing an input.

Step 1 · Determine the domain

Require $x^2-4\ge0$. Factor to obtain $(x-2)(x+2)\ge0$. This holds when $x\le -2$ or $x\ge2$; inputs between $-2$ and $2$ are excluded.

Domain: $D_g=(-\infty,-2]\cup[2,\infty)$.

Step 2 · Determine the range

A real square root is always nonnegative. At $x=-2$ or $x=2$, we have $g(x)=0$. As $|x|$ increases, $x^2-4$ grows without bound, so $g(x)$ does too.

Range: $R_g=[0,\infty)$.

Key point: there is a gap in the domain, although the outputs cover every real value $y\ge0$.

Representing a function in three ways

One function can be communicated in three complementary ways: an equation gives the rule, a table records input–output pairs, and a graph displays those ordered pairs geometrically.

1 Formula (rule)

Let $f(x)=x^2$ with the finite domain $D=\{-2,-1,0,1,2\}$. The formula tells us how to compute the output for each allowed input. For example, $f(-2)=(-2)^2=4$.

2 Table (input–output pairs)

Evaluate the same formula for every input in the stated domain:

$x$−2−1012
$f(x)$41014

These give the ordered pairs $(-2,4)$, $(-1,1)$, $(0,0)$, $(1,1)$ and $(2,4)$.

3 Graph (visual representation)

Each pair $(x,f(x))$ becomes a point. Since this domain contains only five inputs, its graph contains exactly five isolated points—not a solid parabola.

Only five filled points appear because the domain is finite.

QUICK FACT

The formula alone does not tell you the whole graph: the specified domain matters. A table may show a selection of sample values or the entire domain, depending on the question.

4. Piecewise functions and the vertical line test

A piecewise-defined function uses different formulas in different regions of the domain. Your notes use this example:

PIECEWISE EXAMPLE

$h(x)=\begin{cases}-x & x<4,\\0 & x=4,\\x^2 & x>4.\end{cases}$

Try inputs in different pieces

The active rule and value change as the input moves across 4.

Vertical line test

A set of points is the graph of a function of $x$ if every vertical line meets the graph at most once. A vertical line that passes through two points means one input has two outputs.

Why do open and closed endpoints matter?

At $x=4$, neither $-x$ (for $x<4$) nor $x^2$ (for $x>4$) applies. Only $h(4)=0$ is included, so the graph has a filled point at $(4,0)$ and open circles at the other branch endpoints.

Try the vertical line test

Compare a parabola with a circle, and drag the test line left or right. A vertical line touching a graph twice means it is not the graph of a function of x.

5. Evaluating functions, zeros and intercepts

Evaluation

For $q(x)=x^2+4x-3$, replace $x$ by the requested input.

$q(1)=1+4-3=2$.

Zeros and intercepts

An $x$-intercept occurs where $f(x)=0$. A $y$-intercept exists if $0$ belongs to the domain, and has value $f(0)$.

Guided example: $f(x)=\sqrt{x^2-4}$
Find the $x$-intercepts

$\sqrt{x^2-4}=0$ implies $x^2-4=0$, so $x=-2$ or $x=2$. Both are in the domain. The intercepts are $(-2,0)$ and $(2,0)$.

Does the graph have a $y$-intercept?

No. Substituting $x=0$ gives $\sqrt{-4}$, not a real number. Since $0$ is not in the real domain, the graph never intersects the $y$-axis.
