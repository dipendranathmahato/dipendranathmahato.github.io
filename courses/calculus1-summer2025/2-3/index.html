Where we are coming from

In 2.2 · The Limit of a Function, we read limits from tables and graphs, including one-sided and infinite limits.

Tables and graphs suggest the value of a limit; the limit laws let us compute it exactly. For polynomials and many other functions the limit is found by direct substitution. When substitution gives 0/0 we use algebra (factoring and canceling, or multiplying by a conjugate) to find a simpler function with the same limit. The Squeeze Theorem handles functions trapped between two others.

Learning objectives State and use the limit laws; evaluate limits by direct substitution; recognize the indeterminate form 0/0; evaluate limits by factoring and canceling and by multiplying by conjugates; find limits of piecewise functions; use the Squeeze Theorem.

01 · The limit laws

Limit laws

Start with limx→a x = a and limx→a c = c. Let f and g be defined for all x ≠ a on some open interval containing a, with limx→a f(x) = L and limx→a g(x) = M. Then

sum, difference, constant multiplelim (f(x) ± g(x)) = L ± M
lim c·f(x) = c·L
product and quotientlim f(x)·g(x) = L·M
lim f(x)/g(x) = L/M if M ≠ 0
powers and rootslim (f(x))ⁿ = Lⁿ
lim ⁿ√f(x) = ⁿ√L (L ≥ 0 if n is even)
consequencefor a polynomial or a rational function with nonzero denominator at a: lim f(x) = f(a) (direct substitution)

02 · The form 0/0: factor and cancel

Indeterminate form

If substituting x = a gives 0/0, the expression is indeterminate: the limit may be any number, or may not exist. For a rational function, factor numerator and denominator and cancel the common factor (x − a). The simplified function agrees with f for all x ≠ a, so it has the same limit; now substitute. For example, (x² − 2x)/(x² − 4) = x(x − 2)/((x + 2)(x − 2)) = x/(x + 2) for x ≠ 2, so the limit at 2 is 2/4 = 1/2.

03 · The form 0/0 with roots: multiply by the conjugate

Conjugates

For a − b with a, b > 0, (√a − √b)(√a + √b) = a − b. When a limit with a square root gives 0/0, multiply the numerator and the denominator by the conjugate of the expression with the root. The root disappears from that part, a common factor appears, and it cancels.

04 · Limits of piecewise functions

Use the piece on each side

At a point where the formula changes, compute the left-hand limit with the formula for x < a and the right-hand limit with the formula for x > a. The limit exists only if they agree.

05 · The Squeeze Theorem

Squeeze Theorem

Suppose f(x) ≤ g(x) ≤ h(x) for all x ≠ a in an open interval containing a, and limx→a f(x) = L = limx→a h(x). Then limx→a g(x) = L.

For example, −1 ≤ sin(1/x) ≤ 1 for x ≠ 0, so −x² ≤ x² sin(1/x) ≤ x². Since limx→0 (−x²) = 0 = limx→0 x², the Squeeze Theorem gives limx→0 x² sin(1/x) = 0. The same theorem, applied to areas in the unit circle, proves limx→0 (sin x)/x = 1.

Check your understanding · The Limit Laws

Answer each question on paper first, then open the answer to check yourself.

  1. Evaluate limx→2 (2x² − 3x + 1)/(x³ + 4) and name the laws you use.

    Show answer

    The denominator's limit is 2³ + 4 = 12 ≠ 0, so by the quotient law the limit is (2·4 − 3·2 + 1)/12 = 3/12 = 1/4 (sum, constant multiple, and power laws for each part).

  2. Evaluate limx→5 (√(x + 4) − 3)/(x − 5).

    Show answer

    Substitution gives 0/0. Multiply by (√(x + 4) + 3)/(√(x + 4) + 3): the numerator becomes (x + 4) − 9 = x − 5, which cancels, leaving 1/(√(x + 4) + 3) → 1/6.

  3. For f(x) = 4x − 3 if x < 2 and (x − 3)² if x ≥ 2, find the limits at 2.

    Show answer

    limx→2⁻ f(x) = 4·2 − 3 = 5 and limx→2⁺ f(x) = (2 − 3)² = 1. They differ, so limx→2 f(x) does not exist.
