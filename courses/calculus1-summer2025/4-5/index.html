Where we are coming from

In 4.3 · Maxima and Minima, we located absolute and local extrema at critical points.

The first derivative tells us where a graph rises and falls; the second derivative tells us how it bends. Together they locate local maxima and minima and the points where the graph changes from bending upward to bending downward. Note that f′ alone is not enough to draw the graph accurately: two functions can increase on the same intervals and still look very different.

Learning objectives Use the sign of f′ to find intervals of increase and decrease; apply the first derivative test; use the sign of f″ to determine concavity; find inflection points; apply the second derivative test and recognize when it is inconclusive.

01 · Increasing, decreasing, and the first derivative test

The sign of f′

Let f be continuous on an interval I and differentiable inside it. If f′(x) > 0 on I, then f is increasing on I; if f′(x) < 0, then f is decreasing. (The converse needs care: x³ is increasing even though f′(0) = 0.)

First derivative test. Let c be a critical point of a continuous f. If f′ changes from + to − at c, f has a local maximum at c; if from − to +, a local minimum; if f′ has the same sign on both sides, no local extremum.

Example: f(x) = 2x³ − 3x² has f′(x) = 6x² − 6x = 6x(x − 1), with critical points 0 and 1. f′ > 0 on (−∞, 0) and (1, ∞), f′ < 0 on (0, 1): increasing on (−∞, 0) ∪ (1, ∞), decreasing on (0, 1), local max f(0) = 0, local min f(1) = −1.

02 · Concavity and inflection points

Concave up and concave down

Let f be differentiable on an interval I. f is concave up on I if f′ is increasing on I, and concave down if f′ is decreasing. If f″ exists: f″ > 0 on I ⟹ concave up, f″ < 0 on I ⟹ concave down.

A point where a continuous f changes concavity is an inflection point; there f″ = 0 or f″ is undefined. (f″ = 0 alone is not enough: x⁴ has f″(0) = 0 but is concave up on both sides.) For f(x) = 2x³ − 3x²: f″(x) = 12x − 6 is negative for x < 1/2 and positive for x > 1/2, so f is concave down on (−∞, 1/2), concave up on (1/2, ∞), and (1/2, −1/2) is an inflection point.

INTERACTIVE · TANGENT LINES ABOVE AND BELOW

On a concave-up piece the tangent line lies below the graph; on a concave-down piece it lies above.

03 · The second derivative test

Second derivative test

Suppose f′(c) = 0 and f″ is continuous near c.

  • If f″(c) > 0, f has a local minimum at c (concave up, like ∪).
  • If f″(c) < 0, f has a local maximum at c (concave down, like ∩).
  • If f″(c) = 0, the test is inconclusive: use the first derivative test.

Check your understanding · Derivatives and the Shape of a Graph

Answer each question on paper first, then open the answer to check yourself.

  1. For f(x) = 2x³ − 3x², find the intervals of increase and decrease and the local extrema.

    Show answer

    f′(x) = 6x(x − 1). f′ > 0 on (−∞, 0) and (1, ∞), f′ < 0 on (0, 1). Increasing on (−∞, 0) ∪ (1, ∞), decreasing on (0, 1); local max f(0) = 0, local min f(1) = −1.

  2. Find the concavity and the inflection point of the same function.

    Show answer

    f″(x) = 12x − 6, negative for x < 1/2 and positive for x > 1/2. Concave down on (−∞, 1/2), concave up on (1/2, ∞); inflection point (1/2, −1/2).

  3. Why is the second derivative test inconclusive for f(x) = x⁴ at 0?

    Show answer

    f′(0) = 0 and f″(0) = 0. The first derivative test settles it: f′(x) = 4x³ changes from − to +, so 0 is a local minimum. (For x³, also f″(0) = 0, but there is no extremum.)
