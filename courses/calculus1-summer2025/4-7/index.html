Where we are coming from

In 4.5 · Derivatives and the Shape of a Graph, we used f′ and f″ to describe where a graph rises, falls, and bends.

Optimization problems ask for the best choice: the largest area for a given fence, the cheapest can for a given volume, the closest point on a curve. Calculus turns each one into the problem of finding an absolute maximum or minimum of a function of one variable, which we already know how to do.

Learning objectives Identify the quantity to optimize and the variables; use a constraint to write the objective as a function of one variable; find the feasible interval; find and justify the absolute maximum or minimum; answer the question that was asked.

01 · A strategy

  1. Introduce all variables. Draw a picture and label it.
  2. Decide what to maximize or minimize, and write a formula for it (the objective).
  3. Use the constraint to write the objective as a function of one variable, and find the interval of values that make sense.
  4. Use calculus: find the critical points; compare with the endpoints, or use the first or second derivative test.
  5. Answer the question, with units: sometimes the dimensions, sometimes the optimal value.
Example · the garden

A rectangular garden is enclosed by 100 ft of fencing. Let the sides be x and y. Maximize A = xy subject to 2x + 2y = 100, so y = 50 − x and A(x) = x(50 − x) = 50x − x² on [0, 50]. A′(x) = 50 − 2x = 0 at x = 25, and A″(x) = −2 < 0, so this is a maximum. The garden is a 25 ft × 25 ft square with area 625 ft².

03 · Distance problems

Minimize the square of the distance

To find the point on y = √(x + 2), x ≥ −2, closest to (5, 0): a point on the curve is (x, √(x + 2)), at distance D(x) = √((x − 5)² + (x + 2)) = √(x² − 9x + 27). D′(x) = (2x − 9)/(2√(x² − 9x + 27)) = 0 at x = 9/2 (the expression under the root is never 0). D′ < 0 for x < 9/2 and D′ > 0 for x > 9/2, so the closest point is (4.5, √6.5). Since √ is increasing, minimizing D² = x² − 9x + 27 gives the same x with less work.

Check your understanding · Applied Optimization Problems

Answer each question on paper first, then open the answer to check yourself.

  1. Find two positive numbers x and y with x + 2y = 50 for which (x + 1)(y + 2) is as large as possible.

    Show answer

    x = 50 − 2y, so the objective is φ(y) = (51 − 2y)(y + 2) = −2y² + 47y + 102. φ′(y) = −4y + 47 = 0 gives y = 47/4, and φ″ = −4 < 0 confirms a maximum. Then x = 50 − 47/2 = 53/2.

  2. A box with no lid is made from a 12 in × 12 in sheet by cutting squares of side x from the corners. Which x gives the largest volume?

    Show answer

    V(x) = x(12 − 2x)² on [0, 6]. V′(x) = (12 − 2x)(12 − 6x) = 0 at x = 2 (x = 6 gives V = 0). V(2) = 2 · 8² = 128 in³ is the maximum.

  3. Why is it enough to minimize D² instead of D in a distance problem?

    Show answer

    D ≥ 0 and the square root is increasing, so D is smallest exactly where D² is smallest. D² has no square root, so its derivative is simpler.
