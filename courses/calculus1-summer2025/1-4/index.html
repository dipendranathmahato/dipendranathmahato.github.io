Where we are coming from

In 1.3 · Trigonometric Functions, we defined the six trigonometric functions on the unit circle, in radians.

An inverse function runs a function backwards: if f sends a to b, then f⁻¹ sends b back to a. Only one-to-one functions have inverses, so for the trigonometric functions we first restrict the domain. The inverse trigonometric functions will matter later, when we differentiate and integrate.

Learning objectives Explain when a function has an inverse; find an inverse from a formula; relate the graphs of f and f⁻¹; verify inverses by composition; restrict a domain to make a function one-to-one; state the domains and ranges of the six inverse trigonometric functions and evaluate them.

01 · What an inverse does

Idea · Reversing a function

Reversing a function swaps every ordered pair (x, y) to (y, x). The result is a function only if no output of the original was repeated. Such a function is called one-to-one, and its reversal is the inverse function f⁻¹.

Formally, g = f⁻¹ when f⁻¹(f(x)) = x for all x in the domain of f and f(f⁻¹(y)) = y for all y in the range of f. A one-to-one function has an inverse; a constant function, which sends every input to the same output, does not.

Careful: f⁻¹(x) is not 1/f(x). The −1 is a label, not an exponent.

02 · Find the inverse from a formula

How to find f⁻¹

1. Check that f is one-to-one, and write y = f(x).  2. Solve for x in terms of y.  3. Interchange x and y.  4. Write f⁻¹(x) for the result. (Swapping first and solving second gives the same answer.)

For example, y = 3x − 4 gives x = (y + 4)/3, so f⁻¹(x) = x/3 + 4/3.

INTERACTIVE · STEP BY STEP

Choose a function and reveal the algebra one step at a time. Then test the answer: f⁻¹ should send f(x) back to x.

03 · The graph of an inverse: reflect over y = x

Facts · Graphs, domains, and ranges

If (a, b) is on the graph of f, then (b, a) is on the graph of f⁻¹. So the two graphs are reflections of each other over the line y = x, and the domain and range switch: domain of f⁻¹ = range of f, and range of f⁻¹ = domain of f.

INTERACTIVE · MIRROR POINT

Slide the point along the graph of f. Its mirror image (b, a) traces the graph of f⁻¹.

04 · Verify inverses by composition

Test · Inverses undo each other

f and g are inverses exactly when f(g(x)) = x and g(f(x)) = x for every x in the appropriate domains.

08 · Evaluating sin⁻¹, cos⁻¹, and tan⁻¹

Procedure
  1. To find sin⁻¹(a), ask: which angle in [−π/2, π/2] has sine a? For cos⁻¹(a), look in [0, π]; for tan⁻¹(a), look in (−π/2, π/2).
  2. If a is a special value, use the unit circle. Otherwise use a calculator (radian or degree mode as asked).
  3. A negative input sends sin⁻¹ and tan⁻¹ into Quadrant IV (negative angles) and cos⁻¹ into Quadrant II.

09 · Compositions of a function and its inverse

Rules
  • sin(sin⁻¹x) = x and cos(cos⁻¹x) = x for −1 ≤ x ≤ 1 (undefined otherwise); tan(tan⁻¹x) = x for every x.
  • sin⁻¹(sin x) = x only for x in [−π/2, π/2]; cos⁻¹(cos x) = x only for x in [0, π]; tan⁻¹(tan x) = x only for x in (−π/2, π/2).
  • If x is outside the restricted domain, find the angle θ inside it with f(θ) = f(x). Then f⁻¹(f(x)) = θ.
  • For f⁻¹(g(x)): evaluate the inner value g(x) first, then the inverse.

WRAP-UP

Check your understanding · Inverse Functions

Answer each question on paper first, then open the answer to check yourself.

  1. Find the inverse of f(x) = 3x − 4 and check it.

    Show answer

    y = 3x − 4 gives x = (y + 4)/3, so f⁻¹(x) = x/3 + 4/3. Check: f(f⁻¹(x)) = 3(x/3 + 4/3) − 4 = x and f⁻¹(f(x)) = (3x − 4)/3 + 4/3 = x.

  2. Why does f(x) = x² not have an inverse on (−∞, ∞), and how can we fix that?

    Show answer

    f(2) = f(−2) = 4, so f is not one-to-one. On the restricted domain [0, ∞) it is one-to-one, with inverse f⁻¹(x) = √x.

  3. Evaluate sin⁻¹(−1/2), cos⁻¹(−√2/2), and tan⁻¹(√3).

    Show answer

    sin⁻¹(−1/2) = −π/6 (in [−π/2, π/2]); cos⁻¹(−√2/2) = 3π/4 (in [0, π]); tan⁻¹(√3) = π/3.
