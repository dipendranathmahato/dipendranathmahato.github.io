Where we are coming from

In 2.3 · The Limit Laws, we computed limits exactly with the limit laws and algebra.

Informally, a function is continuous if you can draw its graph without lifting your pencil from the paper. Limits make this precise: f is continuous at a when the limit at a exists and equals the value f(a). Continuous functions on closed intervals cannot skip values; that is the Intermediate Value Theorem.

Learning objectives Check the three conditions for continuity at a point; classify discontinuities as removable, jump, or infinite; decide continuity on an interval, using one-sided limits at endpoints; list the families of functions that are continuous on their domains; use the Intermediate Value Theorem to show that an equation has a solution.

01 · Continuity at a point

Definition · Continuous at x = a

A function f is continuous at a if and only if all three conditions hold:

  1. f(a) is defined;
  2. limx→a f(x) exists;
  3. limx→a f(x) = f(a).

If any condition fails, f is discontinuous at a. For example, f(x) = (sin x)/x for x ≠ 0 with f(0) = 1 is continuous at 0, because limx→0 (sin x)/x = 1 = f(0).

02 · Types of discontinuity

removablelimx→a f(x) exists (a finite number), but f(a) is undefined or different. Redefining f(a) as the limit removes the problem.
jumpboth one-sided limits exist but are different: limx→a⁻ f(x) ≠ limx→a⁺ f(x).
infiniteat least one one-sided limit is +∞ or −∞; the line x = a is a vertical asymptote.
a warningif f is continuous at a, then limx→a f(x) exists. The converse is false: the limit can exist while f is discontinuous (a removable discontinuity).

Example: f(x) = (x² − 2x)/(x² − 4) = x(x − 2)/((x + 2)(x − 2)) has domain x ≠ ±2. At x = −2, lim f(x) = ±∞ from the two sides: an infinite discontinuity. At x = 2, lim f(x) = 1/2 but f(2) is undefined: a removable discontinuity.

03 · Continuity on an interval

Intervals and endpoints

f is continuous on an interval if it is continuous at every point of the interval. At an included endpoint only one side is available: f is continuous from the right at a if limx→a⁺ f(x) = f(a), and continuous from the left at b if limx→b⁻ f(x) = f(b).

For example, f(x) = √(x − 4) on [4, 7): at x = 4 we check limx→4⁺ √(x − 4) = 0 = f(4); at an interior point t, limx→t √(x − 4) = √(t − 4) = f(t). So f is continuous on [4, 7) (the point 7 is not included).

INTERACTIVE · SLIDE ALONG THE INTERVAL
Functions that are continuous

Everywhere: polynomials (such as x⁵ + 7x + 5), |x|, exponential functions (eˣ, e−(x + 4)), sin x and cos x.
On their domains: tan x, cot x, sec x, csc x, logₐ x and ln x, √x and ⁿ√x, rational functions. Sums, differences, products, quotients (where the denominator is not 0), and compositions of continuous functions are continuous.

04 · The Intermediate Value Theorem

Intermediate Value Theorem (IVT)

If f is continuous on [a, b] and C is any number between f(a) and f(b), then there is at least one x₀ in [a, b] with f(x₀) = C. (A continuous curve from (a, f(a)) to (b, f(b)) must cross every height in between.)

Example: is there an x in (0, π/2) with cos x = x? Let f(x) = cos x − x, continuous on [0, π/2]. Then f(0) = 1 > 0 and f(π/2) = −π/2 < 0, so by the IVT some θ in (0, π/2) has f(θ) = 0, that is, cos θ = θ.

INTERACTIVE · TRAP THE SOLUTION BY BISECTION

The IVT says a solution exists; halving the interval again and again (keeping the half where the sign changes) locates it.

Check your understanding · Continuity

Answer each question on paper first, then open the answer to check yourself.

  1. State the three conditions for f to be continuous at x = a.

    Show answer

    f(a) is defined, limx→a f(x) exists, and limx→a f(x) = f(a).

  2. Find and classify the discontinuities of f(x) = (x² − 2x)/(x² − 4).

    Show answer

    f is undefined at x = ±2. At x = −2 the one-sided limits are ±∞: an infinite discontinuity. At x = 2, f(x) = x/(x + 2) for x ≠ 2, so the limit is 1/2 while f(2) is undefined: a removable discontinuity.

  3. Show that x³ − x − 1 = 0 has a solution between 1 and 2.

    Show answer

    f(x) = x³ − x − 1 is a polynomial, so it is continuous on [1, 2]. f(1) = −1 < 0 and f(2) = 5 > 0, so by the IVT there is x₀ in (1, 2) with f(x₀) = 0 (x₀ ≈ 1.3247).
