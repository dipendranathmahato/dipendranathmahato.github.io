Differentiation takes a function and gives its rate of change. Often we need to go the other way: from a velocity to a position, or from a rate to a total. A function F with F′ = f is an antiderivative of f. There is never just one: adding a constant does not change the derivative, so the antiderivatives of f form a whole family F(x) + C.

Learning objectives Find antiderivatives by reversing differentiation rules; explain the + C and the family of antiderivatives; use the notation ∫ f(x) dx and the basic formulas; check an antiderivative by differentiating; solve initial-value problems.

01 · Antiderivatives and the + C

Definition

F is an antiderivative of f on an interval I if F′(x) = f(x) for all x in I. If F is one antiderivative, then every antiderivative has the form F(x) + C for a constant C (two functions with the same derivative on an interval differ by a constant).

Example: for f(x) = x², try F(x) = Ax³. Then F′(x) = 3Ax², and 3Ax² = x² gives A = 1/3. So F(x) = x³/3 works, and so does x³/3 + 100: the general antiderivative is x³/3 + C.

02 · Indefinite integrals and basic formulas

Notation and formulas

The indefinite integral ∫ f(x) dx = F(x) + C denotes the general antiderivative. Each differentiation rule, read backwards, gives an integration formula:

powers∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C, n ≠ −1
∫ x⁻¹ dx = ln|x| + C
exponentials∫ eˣ dx = eˣ + C
∫ emx dx = emx/m + C (m ≠ 0)
∫ aˣ dx = aˣ/ln a + C
trigonometric∫ cos x dx = sin x + C, ∫ sin x dx = −cos x + C
∫ sec²x dx = tan x + C, ∫ sec x tan x dx = sec x + C
inverse trigonometric∫ dx/√(1 − x²) = sin⁻¹x + C
∫ dx/(1 + x²) = tan⁻¹x + C

Also ∫ (f ± g) dx = ∫ f dx ± ∫ g dx and ∫ k f dx = k ∫ f dx.

04 · Initial-value problems

Pick one member of the family

An initial-value problem gives F′ (or F″) and the value of F at one point. Find the general antiderivative, then use the given value to find C. Example: F′(x) = 1/√x = x−1/2 and F(1) = 5. Then F(x) = x1/2/(1/2) + C = 2√x + C, and 2√1 + C = 5 gives C = 3: F(x) = 2√x + 3.
