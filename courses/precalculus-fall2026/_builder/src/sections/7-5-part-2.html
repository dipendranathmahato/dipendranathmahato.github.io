Harder equations are solved by reducing them to the linear equations of Part I. If a product equals zero, each factor gives its own simple equation. If the equation is quadratic in sin θ or cos θ, factor it or use the quadratic formula, then reject any value outside [−1, 1]. And if two different functions or angles appear, an identity often rewrites the equation in one function first.

Learning objectives Solve trigonometric equations that are quadratic in form; solve equations in factored form; use identities to solve trigonometric equations.

01 · Equations in factored form

Zero-product property

If A · B = 0 then A = 0 or B = 0. Set each factor equal to zero, solve each simple equation, and collect every solution in the interval. Factor out a common trigonometric function first; do not divide both sides by it, or you lose the solutions where it is zero.

02 · Equations that are quadratic in form

Procedure
  1. Let u = sin θ (or cos θ). The equation becomes au² + bu + c = 0.
  2. Solve for u by factoring or with u = (−b ± √(b² − 4ac))/(2a).
  3. Reject any u outside [−1, 1]: sine and cosine never take those values.
  4. Solve each remaining linear equation in θ.

03 · Using identities to solve equations

Look for a pattern: a difference formula hiding in sin 2x cos x − sin x cos 2x, a double angle sin 2x = 2 sin x cos x, or a Pythagorean identity that replaces cos²x by 1 − sin²x (or sin²x by 1 − cos²x) so that only one function remains.

COMMON MISTAKES
  • Do not divide by sin x or cos x. In 5 cos²x + sin x − 5 = 0 → sin x(−5 sin x + 1) = 0, dividing by sin x would lose x = 0° and 180°.
  • Check every candidate. A value such as cos x = (1 + √10)/3 ≈ 1.39 is not possible and must be rejected.
