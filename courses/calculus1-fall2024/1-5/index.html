Where we are coming from

In 1.4 · Inverse Functions, we undid one-to-one functions and reflected their graphs across y = x.

Exponential functions describe quantities that grow or decay by a fixed percentage, such as a balance earning 4% a year: after t years, P₀ dollars become P₀(1.04)ᵗ. Their inverses are the logarithmic functions. The natural base e will be the star of calculus, because the graph of eˣ has slope exactly 1 where it crosses the y-axis.

Learning objectives Identify exponential functions and their graphs; compare exponential and power growth; simplify with the laws of exponents; explain where e comes from; define logarithms as inverses of exponentials; use the properties of logarithms and the change-of-base formula; solve exponential and logarithmic equations.

01 · Exponential functions

Definition · Exponential function

f(x) = a·bˣ, where the initial value a ≠ 0 and the base b > 0, b ≠ 1. For f(x) = bˣ itself, the domain is (−∞, ∞), the range is (0, ∞), and the graph passes through (0, 1); it increases if b > 1 and decreases if 0 < b < 1. In general the domain is (−∞, ∞); the range is (0, ∞) if a > 0 and (−∞, 0) if a < 0; the y-intercept is (0, a); the horizontal asymptote is y = 0.

02 · Exponential growth beats power growth

bˣ versus xⁿ

In a power function xⁿ the variable is the base; in an exponential function bˣ the variable is the exponent. For small x a power can be larger, but for every b > 1 and every n, bˣ eventually overtakes xⁿ and stays ahead. For example, 2ˣ = x² at x = 2 and x = 4, and 2ˣ > x² for all x > 4.

04 · The number e

The natural base e

As n grows without bound, (1 + 1/n)ⁿ approaches an irrational number, e ≈ 2.718282. It was introduced by Jacob Bernoulli in 1683 and later named by Leonhard Euler. The function f(x) = eˣ is the natural exponential function. Continuous compounding at rate r gives A(t) = Pert.

INTERACTIVE · WATCH (1 + 1/n)ⁿ CLOSE IN ON e

05 · Why e is natural: slope 1 at x = 0

The slope of y = bˣ at (0, 1)

Every graph y = bˣ passes through (0, 1). The slope of the secant line through (0, 1) and (h, bʰ) is (bʰ − 1)/h. As h → 0 these slopes approach the slope of the tangent line at (0, 1). That slope is about 0.69 for b = 2 and about 1.10 for b = 3, and it is exactly 1 for b = e. We will prove this when we study derivatives.

06 · Logarithmic functions

Definition · Logarithm

For b > 0, b ≠ 1, and x > 0: y = logb x ⇔ by = x. So logb x is the inverse function of bˣ: logb(bˣ) = x for all x and blogb x = x for x > 0. The natural logarithm is ln x = loge x, so ln(eˣ) = x and eln x = x. The base stays the base, the logarithm is the exponent, and the argument is the result of the power.

07 · The graph of a logarithm

Characteristics of y = logb x

Domain (0, ∞) and range (−∞, ∞), the reverse of y = bˣ. Vertical asymptote x = 0. Key points (1/b, −1), (1, 0) (the x-intercept), and (b, 1). No y-intercept. Increasing if b > 1, decreasing if 0 < b < 1.

INTERACTIVE · REFLECT bˣ OVER y = x

Slide the reflection from 0% to 100% to watch each point (x, y) travel to (y, x).

08 · Properties of logarithms

Rules (b > 0, b ≠ 1, M > 0, N > 0)

logb1 = 0 and logbb = 1.

Product: logb(MN) = logbM + logbN. Quotient: logb(M/N) = logbM − logbN. Power: logb(Mⁿ) = n·logbM.

INTERACTIVE · TEST A RULE WITH NUMBERS

09 · The change-of-base formula

Change of base

For M > 0 and bases b, n (positive, not 1): logbM = lognM / lognb. With a calculator, use logbM = log M / log b = ln M / ln b.

10 · Solving exponential and logarithmic equations

Strategy
  1. Use the properties to combine everything into a single exponential or a single logarithm on each side.
  2. Undo it: take ln of both sides of an exponential equation; exponentiate both sides of a logarithmic equation.
  3. Solve the resulting algebraic equation.
  4. Check each answer in the original equation: a logarithm needs a positive argument.

  1. Simplify (x³y⁻¹)² / (xy²)⁻² for x, y > 0.

    Show answer

  2. What is special about e?

    Show answer

    e = lim (1 + 1/m)ᵐ as m → ∞ ≈ 2.718282, and it is the only base for which the tangent line to y = bˣ at (0, 1) has slope 1.

  3. Solve ln(2x) − ln(x⁶) = 0.

    Show answer

    ln(2x/x⁶) = 0 gives 2/x⁵ = 1, so x⁵ = 2 and x = ⁵√2 ≈ 1.1487. It is positive, so it is in the domain.
