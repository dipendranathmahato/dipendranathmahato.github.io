Where we are coming from

In 4.10 · Antiderivatives, we found antiderivatives and solved initial-value problems.

We know the areas of rectangles, and of triangles and trapezoids, which can be cut into rectangles. For a region under a curve such as y = x² on [0, 4] no formula applies. We cover the region with n thin rectangles, add their areas, and let n grow. Adding many terms needs a compact notation and a few sum formulas, so we start there.

Learning objectives Use sigma notation and the formulas for 1 + 2 + ⋯ + n, the sum of squares, and the sum of cubes; compute left-endpoint, right-endpoint, and midpoint approximations; decide when an approximation overestimates or underestimates; find an exact area as the limit of Riemann sums.

01 · Sigma notation and sum formulas

Sigma notation

Σi=1n aᵢ = a₁ + a₂ + ⋯ + aₙ. Constants factor out, Σ c·aᵢ = c Σ aᵢ, and sums split, Σ (aᵢ ± bᵢ) = Σ aᵢ ± Σ bᵢ.

sum of the first n integers1 + 2 + ⋯ + n = n(n + 1)/2
sum of squares1² + 2² + ⋯ + n² = n(n + 1)(2n + 1)/6
sum of cubes1³ + 2³ + ⋯ + n³ = [n(n + 1)/2]²
a constantΣi=1n c = nc

02 · Left, right, and midpoint approximations

Riemann sums with equal widths

Divide [a, b] into n subintervals of width Δx = (b − a)/n with endpoints x₀ = a, x₁, …, xₙ = b. The rectangle over [xᵢ₋₁, xᵢ] has height f at the left endpoint, the right endpoint, or the midpoint:

Lₙ = Σi=1n f(xᵢ₋₁)Δx,   Rₙ = Σi=1n f(xᵢ)Δx,   Mₙ = Σi=1n f((xᵢ₋₁ + xᵢ)/2)Δx.

Example: y = x² on [0, 4] with n = 4, Δx = 1. L₄ = (0 + 1 + 4 + 9)·1 = 14 and R₄ = (1 + 4 + 9 + 16)·1 = 30. Since x² is increasing on [0, 4], L₄ underestimates and R₄ overestimates: 14 ≤ A ≤ 30. (For a function that rises and falls, the true area need not lie between Lₙ and Rₙ.)

03 · The exact area as a limit

Let n → ∞

For y = x² on [0, 4]: Δx = 4/n and xᵢ = 4i/n, so

Rₙ = Σi=1n (4i/n)² · (4/n) = (4³/n³) Σ i² = (4³/n³) · n(n + 1)(2n + 1)/6,

and similarly Lₙ = (4³/n³)·(n − 1)n(2n − 1)/6. Both approach (4³/6)·2 = 64/3 as n → ∞, and the area is trapped between them, so A = 64/3.

Answer each question on paper first, then open the answer to check yourself.

  1. Compute L₄ and R₄ for f(x) = x² on [0, 4].

    Show answer

    Δx = 1. L₄ = f(0) + f(1) + f(2) + f(3) = 0 + 1 + 4 + 9 = 14 and R₄ = f(1) + f(2) + f(3) + f(4) = 1 + 4 + 9 + 16 = 30.

  2. Write Rₙ for f(x) = x² on [0, 4] in closed form and find its limit.

    Show answer

    Rₙ = (64/n³)·n(n + 1)(2n + 1)/6 = (64/6)(1 + 1/n)(2 + 1/n) → (64/6)·2 = 64/3.

  3. When does a left-endpoint sum overestimate the area?

    Show answer

    When f is decreasing: the left endpoint is then the highest point of each strip, so each rectangle reaches above the curve.
