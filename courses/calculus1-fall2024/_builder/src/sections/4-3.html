Where does a function reach its highest or lowest value? On a closed interval a continuous function always has a largest and a smallest value, and they can only occur at a few candidate points: where the derivative is zero, where it does not exist, or at the endpoints. Checking those candidates is the closed interval method.

Learning objectives Distinguish absolute and local extrema; state the Extreme Value Theorem; find critical points; state Fermat's theorem correctly, including what it does not say; use the closed interval method to find absolute extrema.

01 · Absolute and local extrema

Definitions

Let f be defined on an interval I and let c be in I. f has an absolute maximum at c if f(c) ≥ f(x) for all x in I, and an absolute minimum at c if f(c) ≤ f(x) for all x in I. f has a local maximum at c if f(c) ≥ f(x) for all x in some open interval containing c, and a local minimum if f(c) ≤ f(x) there.

Extreme Value Theorem. If f is continuous on a closed, bounded interval [a, b], then f has both an absolute maximum and an absolute minimum on [a, b]. Without these hypotheses an extremum may fail to exist.

02 · Critical points and Fermat's theorem

Critical point

c is a critical point of f if c is in the domain of f and f′(c) = 0 or f′(c) is undefined.

Fermat's theorem. If f has a local extremum at c and f is differentiable at c, then f′(c) = 0. So local extrema can only occur at critical points.

The converse is false: f′(c) = 0 does not guarantee an extremum. For f(x) = x³, f′(0) = 0 but 0 is neither a local maximum nor a local minimum. And at a critical point where f′ is undefined there may be an extremum (|x| at 0) or not (∛x at 0).

03 · The closed interval method

Absolute extrema of a continuous f on [a, b]
  1. Find the critical points of f in (a, b) and evaluate f at each.
  2. Evaluate f at the endpoints a and b.
  3. The largest of these values is the absolute maximum; the smallest is the absolute minimum.

Example: f(x) = −x² + 3x − 2 on [1, 3]. f′(x) = −2x + 3 = 0 at x = 3/2. Candidates: f(1) = 0, f(3/2) = 1/4, f(3) = −2. Absolute maximum 1/4 at x = 3/2; absolute minimum −2 at x = 3.
