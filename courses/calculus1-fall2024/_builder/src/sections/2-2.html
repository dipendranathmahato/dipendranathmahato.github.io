The function f(x) = (x³ − 1)/(x − 1) is undefined at x = 1: substituting gives 0/0. But what happens near x = 1? As x gets close to 1 from either side, f(x) gets close to 3. The limit describes this behavior near a point, whatever happens at the point itself.

Learning objectives Use tables and graphs to estimate a limit; explain the intuitive definition of a limit; find one-sided limits and decide whether a two-sided limit exists; recognize infinite limits and vertical asymptotes; read limits from a graph.

01 · The intuitive definition

Definition · Limit

If f(x) becomes arbitrarily close to a single number L as x approaches c from both the left and the right, we say the limit of f(x) as x approaches c is L, and write

limx→c f(x) = L.

The value f(c) plays no role: f(c) may equal L, may be a different number, or may be undefined. For example, limx→1 (x³ − 1)/(x − 1) = 3 even though f(1) is undefined, and limx→0 (sin x)/x = 1.

02 · One-sided limits

Left-hand and right-hand limits

limx→c⁻ f(x) = L means f(x) gets close to L as x approaches c through values less than c; limx→c⁺ f(x) = L uses values greater than c.

limx→c f(x) = L ⟺ limx→c⁻ f(x) = L and limx→c⁺ f(x) = L.

If the two one-sided limits are different, limx→c f(x) does not exist (DNE). This happens often with piecewise functions.

03 · Infinite limits and vertical asymptotes

Infinite limits

limx→c f(x) = +∞ means f(x) grows without bound as x → c from both sides; −∞ is similar. "= ∞" describes how the limit fails to be a number: the limit does not exist as a real number. If either one-sided limit at c is ±∞, the line x = c is a vertical asymptote.

For example, limx→2 1/(x − 2)² = +∞ from both sides. But limx→0⁻ 1/x = −∞ and limx→0⁺ 1/x = +∞, so limx→0 1/x does not exist.

04 · Reading limits from a graph

Two basic limits

limx→a x = a and limx→a c = c for any constant c; for example limx→10 x = 10 and limx→5 2 = 2. More generally, limx→a xⁿ = aⁿ, and limx→a p(x) = p(a) for every polynomial p. Section 2.3 explains why.
