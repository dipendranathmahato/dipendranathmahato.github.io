What happens to f(x) as x grows without bound? The graph may level off at a horizontal line, grow without bound, or follow a slanted line. These limits at infinity describe the end behavior of a function, and together with vertical asymptotes and the information from f′ and f″ they let us sketch a graph accurately.

Learning objectives Compute limits at infinity; find horizontal asymptotes, including different ones at +∞ and −∞; recognize infinite limits at infinity; describe the end behavior of power, polynomial, and rational functions; find oblique asymptotes; combine everything to sketch a graph.

01 · Limits at infinity and horizontal asymptotes

Definitions

limx→∞ f(x) = L means f(x) gets arbitrarily close to L as x increases without bound; limx→−∞ f(x) = L is similar. If either holds, the line y = L is a horizontal asymptote of f. If f(x) → ±∞ as x → ±∞, f has an infinite limit at infinity (and no horizontal asymptote on that side).

Examples: limx→±∞ (2 + 1/x) = 2 + 0 = 2, so y = 2 is a horizontal asymptote; limx→∞ x³ = ∞ and limx→−∞ x³ = −∞. (Recall also the vertical asymptote of 2 + 1/x at x = 0: the limits there are +∞ from the right and −∞ from the left.)

03 · Rational functions and oblique asymptotes

Divide by the highest power of x in the denominator

For f(x) = p(x)/q(x): if deg p < deg q, then f → 0 (asymptote y = 0); if deg p = deg q, f → (ratio of the leading coefficients); if deg p > deg q, f → ±∞. If deg p = deg q + 1, long division gives f(x) = mx + b + r(x)/q(x) with r(x)/q(x) → 0, so the line y = mx + b is an oblique (slant) asymptote.

Example: (x² + x − 6)/(2x² + 6): divide top and bottom by x²: (1 + 1/x − 6/x²)/(2 + 6/x²) → 1/2. The denominator 2x² + 6 ≥ 6 is never 0, so there is no vertical asymptote.

04 · Square roots: two different horizontal asymptotes

√(x²) = |x|

For f(x) = √(6x² + 7)/(x + 7): the denominator is 0 at x = −7, where the one-sided limits are −∞ (left) and +∞ (right), so x = −7 is a vertical asymptote. For the end behavior, √(6x² + 7) = |x|√(6 + 7/x²). As x → +∞, |x| = x and f(x) → √6/1 = √6. As x → −∞, |x| = −x and f(x) → −√6. So there are two horizontal asymptotes, y = √6 and y = −√6.

05 · Guidelines for drawing a graph

  1. Domain of f.
  2. Intercepts (where possible).
  3. Asymptotes: vertical (where the function blows up) and horizontal or oblique (end behavior).
  4. f′: critical points, intervals of increase and decrease, local extrema.
  5. f″: concavity and inflection points.
  6. Plot and connect, using all of the above.
