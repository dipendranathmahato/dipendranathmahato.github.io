Calculus is the study of how functions change, so we begin with functions themselves. A function is a rule that turns each allowed input into exactly one output. In this section we read functions from formulas, tables, and graphs, find their domains and ranges, and get comfortable with the notation we will use all semester.

Learning objectives Use function notation and evaluate functions; find the domain and range of a function and write them in interval or set-builder notation; read functions from tables and graphs; use the vertical line test; work with piecewise-defined functions; find zeros and intercepts.

01 · What makes a rule a function?

Function

A function f is a relation between a set of inputs and a set of permissible outputs that assigns to every input exactly one output. We write y = f(x): y is the value of f at x. Because a function sends each element of the input set to one element of the output set, functions are also called mappings.

  • The set of inputs is the domain. The set of outputs that actually occur is the range.
  • A codomain is any set that contains the range, for example all real numbers.
  • x is the independent variable and y is the dependent variable. On a graph we plot the points (x, f(x)).
POINT TO REMEMBER

Two inputs may share an output: f(1) = 4 and f(−1) = 4 is fine for f(x) = x². What a function cannot do is send one input to two outputs. If a list of data contains f(1) = 3 and f(1) = 5, it is not a function.

02 · Domain, range, and interval notation

Finding the domain of a formula

Unless a domain is given, the domain of f(x) is the set of all real x for which the formula makes sense. Check two things first:

  1. Denominators: we cannot divide by 0. For 3/(x² − 1), exclude x = ±1.
  2. Square roots: the expression under √ must be ≥ 0. For √(4 − 3x), require 4 − 3x ≥ 0, so x ≤ 4/3.

The range is the set of outputs f(x) as x runs through the domain. For f(x) = x² − 4 the range is [−4, ∞), because x² ≥ 0.

Set-builder and interval notation

{x | x has some property} is read "the set of x such that x has the property." Intervals use parentheses for endpoints that are not included and brackets for endpoints that are:

open and closed(a, b) = {x | a < x < b}
[a, b] = {x | a ≤ x ≤ b}
half-open and unbounded[a, b) = {x | a ≤ x < b}
[a, ∞) = {x | x ≥ a}, (−∞, ∞) = ℝ

03 · Evaluating functions

Evaluating f

To evaluate f at an input, replace every x in the formula by that input, in parentheses, and simplify. The input can be a number, a letter, or an expression such as b + 1 or x + h.

A function can also be given by a table of values or by a graph; f(a) is then read from the row x = a, or from the height of the graph above x = a.

COMMON MISTAKES
  • f(b + 1) is not f(b) + 1. Substitute the whole expression: f(b + 1) = (b + 1)² + 4(b + 1) + 3 = b² + 6b + 8.
  • Square the whole input. For f(x) = x², f(−3) = (−3)² = 9, not −3² = −9.

04 · Piecewise functions and the vertical line test

Piecewise-defined function

A piecewise-defined function uses different formulas on different parts of its domain. To evaluate it, first decide which piece the input belongs to, then use that formula.

INTERACTIVE · WHICH PIECE?
Vertical line test

A set of points in the plane is the graph of a function exactly when every vertical line meets it at most once. If some vertical line meets it twice, one input has two outputs.

05 · Zeros and intercepts

Zeros and intercepts

A zero of f is an input x with f(x) = 0; on the graph it is an x-intercept. The y-intercept is the point (0, f(0)), and it exists only when 0 is in the domain.

Useful fact: √A = 0 exactly when A = 0, and x² = a² gives x = ±a.
