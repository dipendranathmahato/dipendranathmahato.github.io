Where we are coming from

In 3.1 · Defining the Derivative, we defined the derivative at a point as a limit of secant slopes.

So far we found the slope of the tangent line one point at a time. Doing it at every x produces a new function: the derivative function f′, which sends each input a to the slope of the tangent line at x = a. Its graph tells us where f rises, where it falls, and where its tangent line is horizontal.

Learning objectives Define f′(x) as a function and use the notations f′(x), dy/dx, y′, d/dx f(x); relate the sign of f′ to where f increases and decreases; sketch the graph of f′ from the graph of f; recognize where a function is not differentiable; compute higher derivatives.

01 · The derivative function

Definition and notation

The derivative function of f is f′(x) = limh→0 (f(x + h) − f(x))/h, defined for every x where the limit exists. For y = f(x) we write f′(x), y′, dy/dx, d/dx f(x).

f′(a) = 0horizontal tangent at x = a
f′(x) > 0 on an intervalf is increasing there
f′(x) < 0 on an intervalf is decreasing there
f′(a) undefinedfor example a corner, a cusp, a vertical tangent, or a break in the graph

A horizontal tangent is where f can change direction, but it does not have to: f(x) = x³ has f′(0) = 0 and is increasing on both sides of 0.

02 · Sketching f′ from the graph of f

Read the slope piece by piece

For the function graphed below: from (−1, −1) to (4, 5) f increases along a curve, so f′ > 0 and decreasing; at (4, 5) the tangent is horizontal, so f′(4) = 0; from (4, 5) to (7, 2) f decreases, so f′ < 0; from (7, 2) to (11, 4) f is a straight line with slope (4 − 2)/(11 − 7) = 1/2, so f′ = 1/2; from (11, 4) to (17, 9) f increases more and more steeply, so f′ > 0 and growing. At (7, 2) the graph has a corner, so f′(7) does not exist.

03 · Where is f differentiable?

Differentiability

f is differentiable at a if f′(a) exists. If f is differentiable at a, then f is continuous at a. The converse fails: a continuous function can have a corner (|x| at 0), a cusp (x2/3 at 0), or a vertical tangent (∛x at 0), and a function is never differentiable where it is discontinuous. Zoom in on a differentiable point and the graph looks like a straight line; zoom in on a corner and it stays a corner.

04 · Higher derivatives

Second, third, … derivatives

The derivative of f′ is the second derivative f″(x) = d²y/dx²; then f‴, f⁽⁴⁾, …, f⁽ⁿ⁾ = dⁿy/dxⁿ. If s(t) is position, s′(t) is velocity and s″(t) is acceleration.

Check your understanding · The Derivative as a Function

Answer each question on paper first, then open the answer to check yourself.

  1. Use the definition to find f′(x) for f(x) = x² − 3x.

    Show answer

    (f(x + h) − f(x))/h = ((x + h)² − 3(x + h) − x² + 3x)/h = (2xh + h² − 3h)/h = 2x + h − 3 → 2x − 3.

  2. Where on its graph does f(x) = x² − 3x have a horizontal tangent, and where is it increasing?

    Show answer

    f′(x) = 2x − 3 = 0 at x = 3/2, so the tangent is horizontal at (3/2, −9/4). f′(x) > 0 for x > 3/2, so f is increasing on (3/2, ∞) and decreasing on (−∞, 3/2).

  3. Is f(x) = |x − 2| differentiable at x = 2? Is it continuous there?

    Show answer

    It is continuous (the graph has no break), but the slope is −1 on the left and 1 on the right: a corner, so f′(2) does not exist.
