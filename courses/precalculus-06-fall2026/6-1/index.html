Where we are coming from

In 5.4 · Right Triangle Trigonometry, in a right triangle, sin = opposite/hypotenuse, cos = adjacent/hypotenuse, and tan = opposite/adjacent.

As a point travels around the unit circle, its y-coordinate rises and falls between −1 and 1 and then repeats. Plotting that height against the angle unrolls the circle into the sine wave; plotting the x-coordinate gives the cosine wave. Four numbers A, B, C, and D then stretch, squeeze, slide, and lift the wave.

Learning objectives Graph variations of y = sin x and y = cos x; use phase shifts of sine and cosine curves.

01 · Unrolling the unit circle

Move x from 0 to 2π. The point on the circle (left) and the point on the graph (right) always have the same height for sine, or the same x-coordinate value for cosine.

02 · Periodic functions and their features

Definitions · Periodic function and period

A function f is periodic if there is a horizontal shift P with f(x + P) = f(x) for every x in the domain. The smallest such positive P is the period. Sine and cosine have period 2π, so sin(x + 2π) = sin x and cos(x + 4π) = cos x.

  • Domain: all real numbers, (−∞, ∞). Range: [−1, 1]. Period: 2π.
  • y = sin x is odd: its graph is symmetric about the origin. y = cos x is even: its graph is symmetric about the y-axis.
INTERACTIVE · SHIFT THE GRAPH UNTIL IT LANDS ON ITSELF

03 · y = A sin(Bx − C) + D and y = A cos(Bx − C) + D

What each number does
A · amplitudeAmplitude = |A| = ½(max − min). |A| > 1 stretches vertically; |A| < 1 compresses; A < 0 also reflects over the midline.
B · periodP = 2π/|B|. |B| > 1 compresses horizontally; |B| < 1 stretches.
C · phase shiftPhase shift = C/B. If C/B > 0 the graph shifts right; if C/B < 0 it shifts left.
D · vertical shiftD > 0 shifts up, D < 0 shifts down. The midline is y = D.
INTERACTIVE · SINUSOID LAB WITH FIVE KEY POINTS

Choose a preset, or type your own A, B, C, D (π can be typed as pi). The dashed gray curve is the parent graph; the green points split one period into four equal parts.

COMMON MISTAKES
  • The phase shift is C/B, not C. In y = sin(2x − π/3) the graph shifts π/6 to the right, not π/3: factor out B, sin(2(x − π/6)).
  • Read C with its sign from Bx − C. In cos(x/2 + π/4), C = −π/4, so the shift is (−π/4)/(1/2) = −π/2: π/2 to the left.

WRAP-UP

Check your understanding · Graphs of the Sine and Cosine Functions

Answer each question on paper first, then open the answer to check yourself.

  1. Find the period of y = 5 sin(πx) and of y = −2 cos(x/4), and say whether each is a horizontal stretch or compression of the parent graph.

    Show answer

    y = 5 sin(πx): P = 2π/π = 2 < 2π, a compression. y = −2 cos(x/4): P = 2π/(1/4) = 8π > 2π, a stretch.

  2. Find the phase shift and its direction for y = sin(πx + π/6) and y = cos(3x − 2).

    Show answer

    sin(πx + π/6): B = π, C = −π/6, C/B = −1/6, so 1/6 unit to the left. cos(3x − 2): B = 3, C = 2, C/B = 2/3, so 2/3 unit to the right.

  3. Find the vertical shift and the midline of y = 2 sin(4x − 1) + 5 and y = −cos(x + π) − 1.

    Show answer

    D = 5: up 5, midline y = 5 (range [3, 7]). D = −1: down 1, midline y = −1 (range [−2, 0]).
