An exponential function answers “what is b raised to this power?” A logarithm answers the reverse question: “what power of b gives this number?” Every logarithm statement is an exponential statement in disguise.

Learning objectives Convert from logarithmic to exponential form; convert from exponential to logarithmic form; evaluate common and natural logarithms.

01 · A logarithm is an exponent

Definition · Logarithm

For b > 0, b ≠ 1, and x > 0: y = logb x ⇔ by = x. The base stays the base, the logarithm is the exponent, and the argument is the result of the power.

03 · Evaluating logarithms

Common and natural logarithms

The common logarithm has base 10: log x means log10 x. The natural logarithm has base e: ln x means loge x. To evaluate a logarithm by hand, set it equal to x, convert to exponential form, and match exponents: log381 = x ⇒ 3ˣ = 81 = 3⁴ ⇒ x = 4.
