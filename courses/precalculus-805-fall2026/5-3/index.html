Where we are coming from

In 5.2 · Unit Circle: Sine and Cosine Functions, the point on the unit circle at angle t is (cos t, sin t).

Sine and cosine are the coordinates y and x of a point on the unit circle. Dividing one coordinate by the other, or taking reciprocals, gives four more functions: tangent, cotangent, secant, and cosecant. Together the six functions are linked by a small set of fundamental identities and by their even and odd symmetries.

Learning objectives Find exact values of secant, cosecant, tangent, and cotangent of π/3, π/4, and π/6; use reference angles to evaluate them; use the even and odd properties; recognize and use the fundamental identities; evaluate trigonometric functions with a calculator.

01 · Six functions from one point

Definitions · The other four functions

If (x, y) is the point where the terminal side of t meets the unit circle, then

tangenttan t = y/x, x ≠ 0
cotangentcot t = x/y, y ≠ 0
secantsec t = 1/x, x ≠ 0
cosecantcsc t = 1/y, y ≠ 0

When a denominator is 0 the function is undefined at that angle; for example, tan(π/2) and sec(π/2) are undefined because x = 0.

02 · Points on a circle of radius r

When the radius is not 1

If (x, y) is on the circle x² + y² = r², the ratios use r:

sine and cosinesin t = y/r, cos t = x/r
tangent and cotangenttan t = y/x, cot t = x/y
secant and cosecantsec t = r/x, csc t = r/y

Use the circle's equation to find a missing coordinate, and the quadrant to choose its sign.

04 · Even and odd functions

Definitions · Even and odd

A function is even if f(−x) = f(x); its graph is symmetric about the y-axis. A function is odd if f(−x) = −f(x); its graph is symmetric about the origin.

  • Even: cos(−x) = cos x and sec(−x) = sec x.
  • Odd: sin(−x) = −sin x, tan(−x) = −tan x, csc(−x) = −csc x, cot(−x) = −cot x.
INTERACTIVE · REFLECT t TO −t

The angle −t is the reflection of t across the x-axis: x stays the same and y changes sign. That is exactly why cosine is even and sine is odd.

05 · Fundamental identities and simplifying

Fundamental identities
quotienttan x = sin x / cos x
cot x = cos x / sin x
reciprocalsec x = 1/cos x, csc x = 1/sin x
cot x = 1/tan x

To simplify, first use the even–odd properties to remove negative angles, then rewrite in terms of sine and cosine.

06 · Evaluating with a calculator

Calculator tips

Calculators have keys for sin, cos, and tan only. Use the reciprocal identities for the others: csc x = 1 ÷ sin x, sec x = 1 ÷ cos x, cot x = 1 ÷ tan x. Do not use the sin⁻¹ key for csc: sin⁻¹ is the inverse function (Section 6.3), not the reciprocal. Always check whether the calculator is in degree or radian mode.

Check your understanding · The Other Trigonometric Functions

Answer each question on paper first, then open the answer to check yourself.

  1. The point (−√2/2, √2/2) is on the unit circle at angle t. Find all six trigonometric values of t.

    Show answer

    sin t = √2/2, cos t = −√2/2, tan t = −1, cot t = −1, sec t = −√2, csc t = √2.

  2. An angle t in Quadrant III has endpoint (x, −4) on x² + y² = 20. Find all six values.

    Show answer

    x² = 20 − 16 = 4 and x < 0, so x = −2; r = √20 = 2√5. sin t = −2√5/5, cos t = −√5/5, tan t = 2, cot t = 1/2, sec t = −√5, csc t = −√5/2.

  3. Simplify sin x (csc(−x) + cot x).

    Show answer

    csc(−x) = −csc x, so sin x(−csc x + cot x) = −sin x · (1/sin x) + sin x · (cos x/sin x) = −1 + cos x = cos x − 1.
