An identity is an equation that is true for every value of the variable for which both sides are defined. The fundamental identities from Chapter 5 let us rewrite any trigonometric expression in many equivalent forms. In this section we use them to verify identities, by turning one side into the other, and to simplify expressions. These skills are what we need later to solve trigonometric equations.

Learning objectives Verify the fundamental trigonometric identities; simplify trigonometric expressions using algebra and the identities.

01 · The identity toolkit

Fundamental identities
Pythagoreansin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x
Reciprocalsin x = 1/csc x, csc x = 1/sin x
cos x = 1/sec x, sec x = 1/cos x
tan x = 1/cot x, cot x = 1/tan x
Quotienttan x = sin x / cos x
cot x = cos x / sin x
Even–oddcos(−x) = cos x, sec(−x) = sec x
sin(−x) = −sin x, csc(−x) = −csc x
tan(−x) = −tan x, cot(−x) = −cot x

02 · Verifying an identity

Strategy · How to verify an identity
  • Work on the more complicated side and transform it, step by step, into the other side. Do not move terms across the equal sign.
  • Add fractions, factor, or square a binomial when you see the chance.
  • Keep an eye on the target expression to choose the next substitution.
  • When stuck, rewrite everything in terms of sine and cosine.

COMMON MISTAKES
  • sin(2x) is not 2 sin x, and sin x / x is not sin: the letters in “sin” are not a factor that can cancel.
  • (sin x + cos x)² is not sin²x + cos²x. Expanding gives sin²x + 2 sin x cos x + cos²x = 1 + 2 sin x cos x.

04 · Identity or not?

A graph or a few test values can show that an equation is not an identity (one counterexample is enough). They cannot prove that it is one; that needs an algebraic verification. Decide for each equation, then use the graph lab above to check.
