Knowing an angle gives its sine. The inverse question, “which angle has sine 1/2?”, has infinitely many answers: π/6, 5π/6, 13π/6, …. To get a function we must agree on one answer. We do that by restricting the domain of sine, cosine, and tangent to an interval where each is one-to-one. Then sin⁻¹, cos⁻¹, and tan⁻¹ return an angle in that interval.

Learning objectives Understand and use the inverse sine, cosine, and tangent functions; find exact values of expressions involving them; use a calculator to evaluate inverse trigonometric functions; find exact values of composite functions with inverse trigonometric functions.

In general f(a) = b ⟺ f⁻¹(b) = a. The inputs of an inverse trig function are ratios; its outputs are angles. Note that sin⁻¹x means the inverse function, not 1/sin x.

02 · Evaluating sin⁻¹, cos⁻¹, and tan⁻¹

Procedure
  1. To find sin⁻¹(a), ask: which angle in [−π/2, π/2] has sine a? For cos⁻¹(a), look in [0, π]; for tan⁻¹(a), look in (−π/2, π/2).
  2. If a is a special value, use the unit circle. Otherwise use a calculator (radian or degree mode as asked).
  3. A negative input sends sin⁻¹ and tan⁻¹ into Quadrant IV (negative angles) and cos⁻¹ into Quadrant II.

03 · Compositions of a function and its inverse

Rules
  • sin(sin⁻¹x) = x and cos(cos⁻¹x) = x for −1 ≤ x ≤ 1 (undefined otherwise); tan(tan⁻¹x) = x for every x.
  • sin⁻¹(sin x) = x only for x in [−π/2, π/2]; cos⁻¹(cos x) = x only for x in [0, π]; tan⁻¹(tan x) = x only for x in (−π/2, π/2).
  • If x is outside the restricted domain, find the angle θ inside it with f(θ) = f(x). Then f⁻¹(f(x)) = θ.
  • For f⁻¹(g(x)): evaluate the inner value g(x) first, then the inverse.

04 · f(g⁻¹(x)) with a reference triangle

Procedure
  1. Let θ = g⁻¹(a). Then g(θ) = a and θ is in the range of g⁻¹; decide its quadrant from the sign of a.
  2. Write a as a ratio of x, y, and r, place the point in that quadrant, and find the missing side with x² + y² = r².
  3. Evaluate f(θ) from x, y, and r, with the sign that matches the quadrant.
